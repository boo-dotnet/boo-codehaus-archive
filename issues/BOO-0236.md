## Description

Currently, BooBinding is not able to resolve inferred types and marks such methods and fields as "unknown type".

You can't see their types when looking at the code completion info of the class containing them, and code completion on them doesn't work.

BooBinding has to create a DynamicReturnType (implementing IReturnType) that is resolved only when needed.
