## Description

The booc nant task now respects the target (ex: nant -t:net-1.1 rebuild) by looking in a subfolder matching the name of the current target to find booc.exe.

This does require keeping at least two copies of the boo dlls and booc.exe however. But that is only necessary if you want to be able to target multiple frameworks.

To create the boo distribution which now includes both net-1.1 and net-2.0 dlls, I do:

nant -t:net-2.0 rebuild update-bin

then

nant -t:net-1.1 rebuild update-bin
