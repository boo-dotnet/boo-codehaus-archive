## Description

Compiling this:

class A: 

 def M[of T](): 

 print typeof(T) 

instance as duck = A() 

instance.M[of string]()

yields this error:

BCE0138: Boo.Lang.Compiler.CompilerError: 'quack' is not a generic definition.

Expected: program compiles without errors and when run it outputs "System.String"
