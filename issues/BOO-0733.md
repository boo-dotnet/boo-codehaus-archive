## Description

The behaviour of some integer operations coupled with type inference can lead to very subtle and difficult to track bugs. Consider this code:

x as duck

x = 5

print x ** 20

y = 5

print y ** 20

z as int

z = 5

print z ** 20

Run with booi or booc, it gives the following results:

95367431640625

-2147483648

-2147483648

When the variable is a "duck", it is automatically promoted to a larger numeric type when int is too small. But when the variable is an "int", it silently saturates the value instead of raising an exception.

The interactive interpreter (booish) has an even more bizarre behaviour:

&gt;&gt;&gt; x=5

5

&gt;&gt;&gt; x**20

95367431640625

&gt;&gt;&gt; print x**20

-2147483648

&gt;&gt;&gt;

...?!!!
