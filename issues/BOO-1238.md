## Description

It would help if we could selectively hide types when importing namespaces. I ran into this problem because of the PropertyAttribute and List classes in NUnit 2.5:

&lt;pre&gt;

import NUnit.Framework

class Foo:

 [property(Bar)] bar as List

&lt;/pre&gt;

This fails, because it uses NUnit.Framework.PropertyAttribute and NUnit.Framework.List, instead of Boo.Lang.Extensions.PropertyAttribute and Boo.Lang.List.

I would like to write:

&lt;pre&gt;

import NUnit.Framework hiding PropertyAttribute, List

class Foo:

 [property(Bar)] bar as List

&lt;/pre&gt;
