## Description

Local variables are still supported though.

```

&gt;&gt;&gt;def dobyref(ref x as int):
... x = 4
... 
&gt;&gt;&gt;x = 1
1
&gt;&gt;&gt;dobyref(x)
----------^
ERROR: The best overload for the method 'Input2Module.dobyref(ref int)' is not compatible with the argument list '(int)'.
&gt;&gt;&gt;// workaround
&gt;&gt;&gt;{ y = x; dobyref(y); x = y }() // local closure variable y can be passed by ref just fine 
&gt;&gt;&gt;x
4

```
