## Description

I tried the following but cannot register the event on a duck type Are

there any workarounds?

import System.Net.Sockets

socket = Socket(AddressFamily.InterNetwork, SocketType.Stream,

ProtocolType.Tcp)

args = SocketAsyncEventArgs()

d = args as duck

handler = def (sender as object, e as SocketAsyncEventArgs):

 pass

// Strongly typed works

args.Completed += handler

// Generates missing field exception

d.Completed += handler

It seems like duck typing doesn't know about events (it is looking for

fields).

I tried explicitly calling add_Completed as well with no luck (missing

method exception).
