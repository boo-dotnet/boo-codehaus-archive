## Description

After a brief discussion with Doug on IRC, it seems that by default the boo lexer/parser applies the IdentTokenFilter class as the default token stream. Although fine well and dandy, this currently makes it impossible to step through whitespace and comment tokens, apparently.

It would be exciting if we had the ability to turn off filtering and step through all available tokens parsed, or at the very least specify what kinds of tokens we would like to see filtered / not filtered.
