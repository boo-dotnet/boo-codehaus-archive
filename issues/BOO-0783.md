## Description

Cannot slice a multidimensional array using just a colon for one of the dimensions.

&gt;&gt;&gt; m = matrix(int,2,2)

(0, 0, 0, 0)

&gt;&gt;&gt; m[0,0:2]

(0, 0)

&gt;&gt;&gt; m[0,:]

System.ArgumentException: Must provide at least one rank.
