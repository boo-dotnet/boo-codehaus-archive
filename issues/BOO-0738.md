## Description

Compiling a file containing a struct with a MarshalAs attribute freezes the compiler – I needed to press Control-C to quit.

Example:

boobugtest.boo

```
import System
import System.Runtime.InteropServices

[StructLayout(LayoutKind.Sequential)]
public struct MyStruct:
 [MarshalAs(UnmanagedType.BStr)] field1 as string
 field2 as string

def Main(args as (string)):
 pass

```

Compiled via "booc boobugtest.boo".

The file compiles fine with the MarshalAs line commented out.

### Snaury, 26/May/06 3:16 AM

After some reading of documentation I found that there is a special method on FieldBuilder: SetMarshal, which can be safely used on CLR1.1. An interesting thing is that although there is a method SetOffset, the same freeze is not happening with FieldOffsetAttribute, i.e. it is processed normally via SetCustomAttribute.

---

### Snaury, 26/May/06 2:46 AM

This is yet another Microsoft CLR bug. When you compile marshal-as.cs on CLR2.0 it works fine. When you compile it on CLR1.1 it freezes. It seems now I finally understood why commercial compilers don't rely on Reflection.Emit at all. :-/
