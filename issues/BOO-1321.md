## Description

This error is thrown for example by this code (on the line with return statement):

```

import System
import System.Collections.Generic

class Foo:

 static def CommandQueue[of T, U] (callback as Action[of T, U]) as Action[of T, U]:
 return do (t as T, u as U):
 commandQueue.Enqueue() do:
 callback (t, u)

 static commandQueue = Queue[of Action] ()

x = Foo.CommandQueue[of int, int]() do(a as int, b as int):
 print a, b

x(3, 4)
Foo.commandQueue.Dequeue()()

```

And this variant that wraps everything in classes (also at return statement):

```

import System
import System.Collections.Generic

class Foo:

 class Enqueuer [of T, U]:
 public cb as Action[of T, U]
 public cq as Queue[of Action]
 public def Invoke (t as T, u as U):
 cq.Enqueue(Closure[of T, U](cb: cb, t: t, u: u).Invoke)

 class Closure [of T, U]:
 public t as T
 public u as U
 public cb as Action[of T, U]
 public def Invoke ():
 cb (t, u)

 class CommandQueuer [of T, U]:
 def Queue (callback as Action[of T, U]) as Action[of T, U]:
 enq = Enqueuer[of T, U] (cb: callback, cq: commandQueue)
 return enq.Invoke

 static commandQueue = Queue[of Action] ()

x = Foo.CommandQueuer[of int, int]().Queue() do(a as int, b as int):
 print a, b

x(3, 4)
Foo.commandQueue.Dequeue()()

```
