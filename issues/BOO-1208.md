## Description

&lt;code&gt;

struct A:

 final v as int

a = A(v:4)

&lt;/code&gt;

It doesn't work as translates to:

&lt;code&gt;

a = A()

a.v = 4 //can't assign to a constant

&lt;/code&gt;

It would be better to have automatic constructor generated and called.
