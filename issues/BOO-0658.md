## Description

Unit Tests--&gt; "Run with code coverage" crashes. NCover appears to start up fine, but nunit-console crashes.

The relevant bit of the exception is, 

Unhandled Exception:

System.Reflection.TargetInvocationException: Exception has been thrown by the target of an invocation. ---&gt; System.IO.FileNotFoundException: Assembly not found: C:\Documents

 at NUnit.Util.NUnitProject.FromAssemblies(String[] assemblies)

 at NUnit.ConsoleRunner.ConsoleUi.MakeTestFromCommandLine(TestDomain testDomain, ConsoleOptions parser)

I see this error frequently when you start a command line program but forget to encapsulate the directory with quotation marks.
