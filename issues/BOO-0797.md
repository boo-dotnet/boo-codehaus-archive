## Description

Boo assemblies currently report version 1.0.0.0 regardless of build number and framework version. This causes several problems and needs to be remedied soon. The 0.7.7 release is a good place to start correctly versioning the assemblies, if we want the release number to be part of the version number (since it's too late for 0.7.6 and 0.7.8 is too far ahead).

See:

http://groups.google.com/group/boolang/browse_frm/thread/6965f4ad8a918f3b

http://groups.google.com/group/boolang/browse_frm/thread/535fe3657e5ceab0
