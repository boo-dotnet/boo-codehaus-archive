## Description

I found that NAnt tasks don't support embedding arbitrary resources (not *.resource format) in assemblies when adding them with &lt;resources&gt;.

The reason for this is NAnt passing "-resource" command line option while booc.exe expects "-embedres". I'm attaching a proposed patch that fixes this issue.

I haven't performed any serious testing other than checking that it works in my case:

 &lt;booc target="exe" output="$
{sooda.dir}/Sooda.BooTest.exe" debug="true"&gt;

 &lt;references&gt; 

 &lt;include name="${sooda.dir}

/NLog.dll" /&gt;

 &lt;include name="$
{sooda.dir}

/Sooda.dll" /&gt;

 &lt;include name="System.Data.dll" asis="true" /&gt;
