## Description

The following is an attempt to use generic explicit interfaces in boo: 

```
interface One[of T]:
 def Foo() as T

interface Two[of T]:
 def Foo() as T

class Impl (One[of int], Two[of string]):
 def One[of int].Foo() as int:
 return 12
 def Two[of string].Foo() as string:
 return "yes"
```

It generates these errors:

```
Boo Compiler version 0.9.2.3453 (Mono 2.4.2.3)
explicit-generic-2.boo(8,19): BCE0043: Unexpected token: ].
explicit-generic-2.boo(8,24): BCE0044: expecting "RBRACK", found '('.
explicit-generic-2.boo(10,22): BCE0043: Unexpected token: ].
explicit-generic-2.boo(10,27): BCE0044: expecting "RBRACK", found '('.
4 error(s).
```

The following C# equivalent compiles:

```
interface One&lt;T&gt; { T Foo(); }
interface Two&lt;T&gt; { T Foo(); }

class Impl : One&lt;int&gt;, Two&lt;string&gt;
{ 
 int One&lt;int&gt;.Foo() { return 12; }
 string Two&lt;string&gt;.Foo() { return "yes"; }
}
```
