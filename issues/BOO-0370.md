## Description

In the following code, "ac" get initialised before "action", though the initializer of "ac" uses "action" and is declared after.

callable handler(a as int) as int

class Action:

 cb as handler

 def constructor(callback as handler):

 cb = callback

class A:

 val = 0

 a as Action

 b as Action

 action2 as handler = def(para):

 print("callback " + self)

 newa = A(32)

 ac2 as Action = Action(action2)

 action as handler = def(para):

 print ("Hello World " + val)

 ++val

 ac as Action = Action(action)

 def constructor(p):

 print("CONSTRUCTOR")

 val = p

 a = ac

 b = ac2

c = A(3)

a = A(4).action

b = A(5).action

a(0)

b(0)

b(0)

a(0)

c.a.cb(0)

c.b.cb(0)

c.a.cb(0)

c.b.cb(0)

However, if we move action and ac before action2 and ac2, then the order gets correct ! If I remove the line "newa = A(32)" in the closure body of action2, the order also becomes correct.
