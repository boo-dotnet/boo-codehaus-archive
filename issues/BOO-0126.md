## Description

Today:

a = array(int, 2)

is emitted as a builtin method invocation followed by a cast to the exact type.

There are two main optimization strategies:

1) the EmitAssembly step should be able to recognize this pattern and emit the equivalent bytecode;

2) the ProcessMethodBody step would replace this pattern by a new AST node, ArrayConstructorExpression with the type and dimensions of the array;

I've opted to augment the emitter. The two main array constructors were optimized:

 a = array(int, 2)

 b = array(byte, (1, 2, 3))

these two forms will now generate very lean and mean IL code.

Preliminary tests show a 300% speedup on ms.net and 200% speedup on mono.
