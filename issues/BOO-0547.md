## Description

If the concept of doing an assignment inside of a conditional does not fade from the Boo language, it would be nice to only show a warning on reassignment rather than for every assignment done in a conditional. This is intended to cut down on some of the errors, since assigning a conditoinal in an if statement can be intentional and done multiple times, leaving developers to start ignoring the warnings all together.
