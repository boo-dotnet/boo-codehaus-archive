### Toby Miller, 26/Jul/04 3:15 PM

1. Modified form of except clause. It was 'except &lt;name&gt; as &lt;type_ref&gt;:'. Its been updated as the following 'except [&lt;name&gt; [as &lt;type_ref&gt;]]:'. If type_ref is not provided, then it is set to System.Exception.

2. The parser was updated to verify that a reraise (raise w/o arguments) can only occur within an except clause.

3. EmitAssembly step modified to emit a Rethrow opcode if its exception expression is null.

4. Added several test cases.

### Rodrigo B. de Oliveira, 26/Jul/04 3:28 PM

Great work, Toby! Thanks again!

One comment: I think it's better to leave all the semantic checking for after the parsing, that way, different parsers could be used (or no parsers at all in the case of the users generating an ast by hand) without losing any of the functionality. More specifically I will move the empty except clause completion and empty raise error checking to the ProcessMethodBodies step.
