## Description

Currently, closure names give no clue to which method they came from:

 InteractiveInterpreter.___closure18

A more readable version would be in the form &lt;original method name&gt;$closure$&lt;unique value&gt;:

 InteractiveInterpreter.InitializeRepresenters$closure$18
