## Description

Right now if I want to grab the AST node located at a lexical position, I have to manually dive into the target module and drill down, keeping a copy of the "last valid" ast node until I finally hit an AST node whose lexical info is greater than the last valid node and greater than the target lexical info. Fuzzy resolution.

It is a suprising amount of work and prone to errors!

It would be nice to be able to arbitrarily retrieve AST nodes by type or lexical information.

Here is some poorly thought-out sample code:

#'context' is a CompilerContext

context = boo.Run()

code = CodeInformationService(context.CompileUnit) #accepts any valid 'node'

node = code.GetNodeAt(line, column, filename)

#alternatively, if you've passed a Module instead of a CompileUnit ...
