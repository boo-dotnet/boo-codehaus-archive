## Description

I seems that the current antlr grammar which generates the lexer has ab bug when i need to have an " quote at the end of my multiline string.

Steps to reproduce:

Start booish
 
Type&gt; test = """"hallo"world"""
 
Works
 
Type&gt; test = """hallo"world""""
 
ERROR: unexpected char: 0xD.

Currently the lexer stops at the first full """, but i should lex all to the last full """.

Currently it lexes like this:

"""hello"world"""""""""""""""

^^-----------^^

But i should lex like this:

"""hello"world"""""""""""""""

^^-----------------------^^
