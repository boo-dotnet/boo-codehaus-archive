## Description

mono command line tools generally support the --pkg:&lt;package name&gt; option that allows a bunch of references (a package) to be automatically included.

add such a support to booc.

the basic idea is:

 def getPackageReferences(packageName as string):

 return shell("pkg-config", "--libs $
{packageName}

")
