## Description

The following code results in Program.boo(8,6) : Error BCE0055: Internal compiler error: Operation is not valid due to the current state of the object. It compiles and runs fine if the subclass is cast to the base class...

```
import System
import System.Collections.Generic

class MyList[of T](List[of T]):
 pass

l = MyList[of int]()
l.Add(1)
print l[0]

```
