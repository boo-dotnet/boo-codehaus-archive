## Description

for key, value in hash would be so nice to have.

for key, value in hash:

 DoSomething(key, value)

translates to:

for __item in hash:

 key = __item.Key

 value = __item.Value

 DoSomething(key, value)

I just wanted to note if this is implemented, I would like to see unpacking for any struct. This could be useful for anonymous structs too (tuples). I'm not sure if it is necessary to be able to iterate over structs, however "for item in mystruct". But unpacking could be very useful.

One issue though. I noticed in many test cases the [Property] macro is used in structs with fields that have no modifier set. Fields are public by default in structs, as are properties. So in this case you would unpack both the property and the field unless you explicitly mark the field as protected or private. Perhaps the property macro could set the field to be protected if no modifier is set and it is in a value type class (struct). Or an even better solution is BOO-482 I think, but either way would work fine.
