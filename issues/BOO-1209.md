## Description

```
class ParGeneric[of T(struct)]:
 [property(Value)]
 protected val as T
 
class Representor:
 internal abstract def upload():
 pass

class RepGeneric[of T(struct)](Representor):
 private final param as ParGeneric[of T]
 internal def constructor(par as ParGeneric[of T]):
 pass
 internal override def upload():
 pass
 
class ShaderAuto:
 private final params = List[of Representor]()
 public def data[of T(struct)](p as ParGeneric[of T]):
 params.Add( RepGeneric[of T](p) )
 public def use():
 for p in params:
 p.upload()

```

### Dmitry Malyshev, 13/Jul/09 10:34 AM

More simple case of unnecessary warning:

```

class A:
 internal def f2():
 f1()
 private abstract def f1():
 pass

class B(A):
 private override def f1():
 print 1

q as A = B()
q.f2()

```

In this case overriding method is treated as unused while it can be called from A.f2()
