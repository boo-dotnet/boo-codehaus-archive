## Description

&lt;snip&gt;

generator = i*2 for i in range(10)

for j in generator:

 print(j+1)

&lt;/snip&gt;

The code above fails to compile the expression j+1 because the compiler is not able to infer that the generator yields integer values (i*2) thus typing the j loop variable as object.
