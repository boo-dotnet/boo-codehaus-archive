## Description

In boo 7.6 and earlier it was possible to do the following:

bruce = 5

print bruce,

bruce = 7

print bruce

passing that as a file to booi would return:

5 7 

Not it returns an "unexpected character EOL" because the comma is not allowed to be the last character in the macro, it expects another expression. This eliminates the helpful feature of being able to suppress the newline when calling the print macro.
