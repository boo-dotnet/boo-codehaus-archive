## Description

When trying to compile this (invalid) two-line program:

struct Foo:

 Foo

The compiler crashes with a StackOverflowException in step 'MacroAndAttributeExpansion'.

In my case (parsing for code completion inside SharpDevelop), this takes down the whole SharpDevelop process.
