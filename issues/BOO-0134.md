Hi Doug,

a switch-like statement is already planned (the parser even recognizes the syntax already):

given value:

 when 3:

 print("woohoo!")

 when "foo":

 print("really?")

"given" will be necessary for yield to work the way I want it to (a state machine with jumps to apropriate locations on the generator method) so I'll be implementing given for integer values in the next couple of days. 

Generic "given" accepting string values and whatnot will be left for a further release unless someone else comes along and do it...
