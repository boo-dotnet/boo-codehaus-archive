## Description

I'd like to see this features available for syntax colorization / highlighting, if any of them are really possible.

*Highlighting for method signature names: eg highlight "Add" in the signature "def Add"

*Highlighting member references. Eg, color members differently from local variables. eg, "Class.Member" or "Member" by itself.

## Comments (1)

---

### Daniel Grunwald, 27/Nov/05 2:58 PM

The syntax highlighting engine is too primitive to support this, but a custom HighlightingStrategy that uses the resolver could work. The implementation would require binding all nodes to ResolveResults in the background, so I'll leave this for SharpDevelop 2.1.
