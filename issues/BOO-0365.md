## Description

This will make boo more friendly to coroutine lovers.

An yield statement without an expression will be equivalent to 'yield &lt;zero value for the inferred domain&gt;', in other words:

def foo():

 yield 1

 yield # equivalent to yield 0

 yield 3

def bar():

 yield "foo"
