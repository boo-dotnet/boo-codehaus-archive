## Description

Nested functions can't call themselves recursively in neither 0.8.1.2865 nor trunk (r2896). Unfortunately, this happens to be my typical use of nested functions: for handling some recursive data when I need just a tiny helper to walk the data.

Consider this artificial example:

def do_sum(x as int):

 def sum_up_to(x as int) as int:

 if x == 0:

 return 0

 return x + sum_up_to(x-1)
