### Sorin Ionescu, 25/Oct/05 10:09 AM

It doesn't report the wrong file name. If file information is not available (this happens when there is a fatal compiler error, such as Main not found, or no inputs specified), it is common to report the compiler name in place of the file name. It's the same with CSC, VBC, etc.

---

### Daniel Grunwald, 25/Oct/05 6:38 AM

SharpDevelop uses the filename reported by the MsBuild task.

If you run booc on the code, you'll an error message without any file information.

If booc.exe doesn't report where the error is, SharpDevelop cannot show the correct file name.
