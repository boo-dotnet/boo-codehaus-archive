## Description

Two aspects of generic constraints are missing.

http://msdn.microsoft.com/en-us/library/d5x73970.aspx describes a "new()" generic constraint, requiring that the generic specified have a default constructor.

http://msdn.microsoft.com/en-us/library/xwth0h0d.aspx describes the "default" keyword for Generics: the keyword can be used inside the generic to invoke the default constructor

```
class Foo[of T(new)]:
 def IsDefault(t as T):
 return t == default(T)
```

I'll further point out the attempted workaround:

```
class Foo[of T]:
 default = T()
 def IsDefault(t as T):
 return t == default
```

Produces:

```
BCE0155: Instantiating generic parameters is not yet supported.
```

### Cedric Vivier, 22/Jul/09 8:39 PM - edited

The default constructor constraint is already implemented:

```

class[of T(constructor)]

```

Default(T) has its own issue =&gt; BOO-1226

Also default does not call the default constructor per-so, it just returns an zero-initialized instance of T if it is a value type, or null if it is a reference type.
