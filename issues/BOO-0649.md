## Description

I currently have to softlinks any libraries i want to link into /usr/lib. Furthermore, it requires really careful scripting to get items to link. 

The following are tried without the /usr/lib softlink, and show the error generated follow by the permuatations which result in that error

BCE0041: Failed to load assembly '/usr/lib/mono/1.0/System.Web.dll'. :

import System.Web from "/usr/lib/System.Web.dll"

import System.Web from "/usr/lib/mono/1.0/System.Web.dll"

import System.Web from "/usr/lib/mono/gac/System.Web/1.0.5000.0__b03f5f7f11d50a3a/System.Web.dll"

booc -r:/usr/lib/mono/1.0/System.Web.dll AND import System.Web.from "/usr/lib/mono/1.0/System.Web.dll"

Fatal error: Argument cannot be null..

booc -r:System.Web.dll sample.boo

booc -r:System.Web.dll AND import System.Web from "/usr/lib/mono/1.0/System.Web.dll"

booc -r:System.Web.dll AND import System.Web from "System.Web.dll"

booc -r:/usr/lib/mono/1.0/System.Web.dll AND import System.Web from "System.Web.dll"

booc -r:/usr/lib/gac/System.Web/1.0.5000.0_b03f5f7f11d50a3a/System.Web.dll booencode.boo AND import System.Web from "/usr/lib/mono/gac/System.Web/1.0.5000.0_b03f5f7f11d50a3a/System.Web.dll"

I'm sure i've forgotten some. The one oddity I picked out was

booc -r:/usr/lib/gac/System.Web/1.0.5000.0_b03f5f7f11d50a3a/System.Web.dll booencode.boo AND import System.Web from "/usr/lib/mono/gac/System.Web/1.0.5000.0_b03f5f7f11d50a3a/System.Web.dll"

booc -r:/usr/lib/mono/1.0/System.Web.dll AND import System.Web.from "/usr/lib/mono/1.0/System.Web.dll"

The bottom references the /usr/lib/mono/1.0/System.Web.dll link which points to the above actual System.Web.dll file. However, it generates a "BCE0041: Failed to load assembly '/usr/lib/mono/1.0/System.Web.dll'." rather than the "Argument cannot be null" error.

Anyways, the only solution I've found is to softlink whatever I want to reference into /usr/lib. However even still it's sympotmatic.

import System.Web.dll from "/usr/lib/System.Web.dll":

BCE0041: Failed to load assembly '/usr/lib/System.Web.dll'.

booc -r:System.Web.dll

Fatal Error: Argument cannot be null..

Otoh, import System.Web from "System.Web.dll" does work, as does booc -r:/usr/lib/System.Web.dll.

Oddly, import System.Web alone simply does not import the library as expected; its utilities are still inacessible from my sample.boo program;

print System.Web.HttpUtility.UrlEncode("testing, url'encode this!")

### Doug H, 01/Mar/06 10:46 AM

This should work in current builds of boo. There are versions that target 1.0 in the bin subfolder and 2.0 in the bin/net-2.0 subfolder.

Still I would not recommend referencing dlls in the gac using the full path: usr/lib/mono/gac/System.Web/1.0.5000.0__b03f5f7f11d50a3a/System.Web.dll
