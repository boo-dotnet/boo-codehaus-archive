## Description

The following two lines are terrible:

return cast(int, peerInfo &amp; PeerInfo.Connected) != 0

peerInfo &amp;= cast(PeerInfo, ~cast(int, PeerInfo.Connected))

The proper way is:

return peerInfo &amp; PeerInfo.Connected != 0

peerInfo &amp;= ~PeerInfo.Connected
