## Description

I am attempting to create a facimile of the following C# code in Boo:

```
using System.Collections.Generic;

interface MyClass {}

class MyGeneric &lt;M,L&gt; 
 where M : MyClass
 where L : IList&lt;M&gt; {}

class MySimplerGeneric &lt;Z&gt; : MyGeneric&lt;Z,IList&lt;Z&gt;&gt;
 where Z : MyClass {}
```

This is the boo version:

```
import System.Collections.Generic

interface MyClass:
 pass

class MyGeneric[of M(MyClass), L(IList of M)]:
 pass

class MySimplerGeneric[of Z(MyClass)] (MyGeneric[of Z,IList[of Z]]):
 pass
```

The boo rendition produces the erronious error message:

BCE0149: The type 'System.Collections.Generic.IList[of MyClass]' must derive from 'MyGeneric[of M, L]' in order to substitute the generic parameter 'L' in 'MyGeneric[of M, L]'.

There ought be no error message. The second parameter, L, ought not derive from MyGeneric[of M,L], but of IList[of M].

It is interesting to note that converting the "class" keywords in the boo example to "interface" works fine.
