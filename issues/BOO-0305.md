## Description

It would be nice to have slice assignment in Boo in the following cases

#case 1: swap array members

a = (1,2)

a[0],a[1] = a[1],a[0]

assert a == (2,1)

#case 2: assign array to slice

a = (1,2,3)

a[1:3] = (4,5) //Something like (4,5).CopyTo(a, 1) if len(slice) == len((4,5))

assert a == (1,4,5)
