In a sandboxed environment you would not have an earlier version of Boo in the GAC no? 

Big refactoring has been done between 0.9.0 and 0.9.1, that's why you need to remove Boo.Lang.Extensions from the GAC before compiling Boo 0.9.1 (gacutil -u Boo.Lang.Extensions) because the newly built Boo.Lang.Compiler try to find a type that does not exist in the older incompatible one loaded from the GAC.
