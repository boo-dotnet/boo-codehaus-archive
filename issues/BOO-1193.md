## Description

We have, as in C#, a shorthand for attributes ie. [Foo] is considered as [FooAttribute] in an attribute context.

I propose to allow shorthand for exceptions in a "raise context" such as "raise InvalidOperation()" is the same as "raise InvalidOperationException()"

(the fallback to +"Exception" being only done if the type "InvalidOperation" has not been found of course)

Opinions?
