## Description

When invoking a method or referencing a field on a mixed generic type that was inherited from another generic type, a compiler error is generated in the EmitAssembly step, saying "Method must not be dynamic or global, and must be declared on a generic type definition".

This has to do with a bug in Microsoft's .NET Reflection API. See here for details: http://connect.microsoft.com/VisualStudio/feedback/ViewFeedback.aspx?FeedbackID=97424
