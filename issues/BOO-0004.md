## Description

The compiler already includes support for standard generator expressions:

 generator = i*2 for i in range(10)

The type of such expression is compatible with System.Collections.IEnumerable.

List generators as shortcuts for list creation:

 l = [i*2 for i in range(10)]

so it should also support array generators as a shortcut for array creation:

 a = (i*2 for i in range(10))

The expression would be evaluated immediately (just like list generators) and its resulting type would be (generator item type) - array of whatever type the intern generator yields.
