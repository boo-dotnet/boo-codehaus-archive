## Description

Support explicit member implementation for generic types

Test case:

```
using System.Collections.Generic
class FooEnumerator (IEnumerable[of object]):
 def IEnumerable[of object].GetEnumerator() as IEnumerable[of object]:
 for i in range(1,10):
 yield i

```

Currently gives:

BCE0043: Unexpected token: ]. BCE0044: expecting "RBRACK", found '('.
