## Description

In the source file:

src/Boo.Lang.Compiler/CompilerParameters.cs

line: 185

revision: 3287

there is a cast of a CompilerReferenceCollection in IList.

But CompilerReferenceCollection does not implement IList interface. It derives of Boo.Lang.Compiler.Util.Set&lt;TICompileUnit&gt;

So the setter BooAssembly always throws NullReferenceException. 

public Assembly BooAssembly

{

 get
 {
 return this._booAssembly;
 }

 set

 {

 if (value != null)
 {
 (this._compilerReferences as IList).Remove(this._booAssembly);
 this._booAssembly = value;
 this._compilerReferences.Add(value);
 }

 }
