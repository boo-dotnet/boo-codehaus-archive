## Description

The following code sample throws an exception whenever you try to right click on "string" in the method signature "temp." In a large document, the multiline hash declaration "primitives" actually breaks code completion everywhere, as well.

This is caused by the trailing comma after the last item in primitives.

The exception is below the code sample.

def temp(s as string):

 pass

static primitives = 
{ "System.Double" : "double",
 "System.Single" : "single", 
 }

Exception thrown: 

System.ArgumentOutOfRangeException: line number must be &gt;= 0

Parameter name: lineNumber
