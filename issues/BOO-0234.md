## Description

A version of "map" that puts the callable parameter last, to allow passing multiline closures.

src/Boo/Lang/Builtins.cs:

 public static IEnumerable map(object enumerable, ICallable function)
 {
 return map(function,enumerable);
 }

//test.boo

//existing way - callable is the 1st parameter

newlist = map(
{x as int | return x*x*x}

, [1,2,3,4,5,6])

//new way - callable can be passed last, too.

newlist = map([1,2,3,4,5,6]) def (x as int):

 return x*x*x
