## Description

abstract class AbstractOne:

 abstract def Foo() as string:

 pass

 class MyClass:

 def doit():

 print "abstractone.myclass.doit"

class ConcreteOne:

 def Foo() as string:

 m = MyClass()

 m.doit()

 class MyClass:

 def doit():

 print "concreteone.myclass.doit"

//InternalError: specified cast is not valid

class TestAbstract(AbstractOne):

 override def Foo():

 print "testabstract.foo"

//works

class TestConcrete(ConcreteOne):

 override def Foo():

 super()

t = TestAbstract()

t.Foo()

t = TestConcrete()

t.Foo()

### Doug H, 09/Nov/04 4:55 PM

It looks like the cast error is at line 4690 in ProcessMethodBodies under the ResolveAbstractMembers method.

If you change the line from this:

foreach (IMember member in baseType.GetMembers())

to this:

foreach (IEntity member in baseType.GetMembers())

It appears to work, although I am not sure if this is a "real" fix to the issue (do abstract classes inside an abstract class need to be checked? I don't think so).
