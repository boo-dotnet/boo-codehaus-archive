## Description

```
import System.ComponentModel

interface ISaveHandler:
 def Save()

 PostSave as callable(RunWorkerCompletedEventArgs):
 get
 set

class SaveHandler(ISaveHandler):
 def Save():
 pass

 [property(PostSave)]
 private _postSave as callable(RunWorkerCompletedEventArgs)

```

Error BCE0035:

'HMR.AppShell.QueryObject2_.QueryObjectSaveHandler.PostSave' conflicts

with inherited member 'HMR.AppShell.Mdi.ISaveHandler.PostSave'.
