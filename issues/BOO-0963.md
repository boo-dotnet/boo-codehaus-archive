## Description

```
import System.ComponentModel

interface ISaveHandler:
 def Save()

 PostSave as callable(RunWorkerCompletedEventArgs):
 get
 set

class SaveHandler(ISaveHandler):
 def Save():
 pass

 [property(PostSave)]
 private _postSave as callable(RunWorkerCompletedEventArgs)

```

Error BCE0035:

'HMR.AppShell.QueryObject2_.QueryObjectSaveHandler.PostSave' conflicts

with inherited member 'HMR.AppShell.Mdi.ISaveHandler.PostSave'.

### Curtis Schlak, 24/May/08 4:37 PM

This is a bug. If you have the following files

File: asm1.boo

```

import System.ComponentModel

interface ISaveHandler:
 def Save()

 PostSave as callable(RunWorkerCompletedEventArgs):
 get
 set

```

File: asm2.boo

```

import System.ComponentModel

class SaveHandler(ISaveHandler):
 def Save():
 pass

 [property(PostSave)]
 private _postSave as callable(RunWorkerCompletedEventArgs)

```

and run the following commands

booc -t:library -o:asm1.dll asm1.boo

booc -t:library -o:asm2.dll -reference:asm1.dll asm2.boo

you get the compiler error 

asm2.boo(7,9): BCE0035: 'SaveHandler.PostSave' conflicts with inherited member ' ISaveHandler.PostSave'.

This occurs because the compiler-generated delegate in asm1.dll (on a sample run) has type 

```
CompilerGenerated.__ISaveHandler_PostSave$callable0$6_20__, asm1, Version=0.0.0.0, Culture=neutral
```

and the compiler-generated delegate in asm2.dll has type

```
CompilerGenerated.__SaveHandler_PostSave$callable0$8_29__, asm2, Version=0.0.0.0, Culture=neutral
```

As far as I understand the default pipeline, the TransformCallableDefinitions step occurs far before the ProcessInheritedAbstractMembers step where this fails.

To fix this bug, I would postulate that Boo could implement one of the following (or another choice altogether):

have something to indicate to the compiler that the callable should transform into the same type of callable from another class; or,
 
have the compiler infer the Type of the callable because it overrides or implements a method external to the callable-generating algorithm.
