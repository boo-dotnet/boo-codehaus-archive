## Description

As an improvement of BOO-1146, it should be possible to easily reference directly parent macro definition arguments from nested macros, without needing to manually find/check/cast the correct argument.

Testcase:

```
"""
Jerry whispers: Hey! You wanna get back in the house, don't you?
Tom says: Yeah
Jerry shouts: OKAY THEN!
"""
import Boo.Lang.PatternMatching

macro character(name as string):

 macro whispers(text as string):
 #old: name = cast(StringLiteralExpression, character.Arguments[0]).Value
 yield [| print "${$(character['name'])} whispers: ${$text}" |]

 macro says(text as string):
 yield [| print "${$(character['name'])} says: ${$text}" |]

 macro shouts(text as string):
 yield [| print "${$(character['name'])} shouts: ${$(text.ToUpper())}" |]

character "Jerry":
 whispers "Hey! You wanna get back in the house, don't you?"
character "Tom":
 says "Yeah"
character "Jerry":
 shouts "Okay then!"

```
