## Description

boo should provide a way to describe the exact type of callable 

arguments. Take a simple map function definition for instance, how to properly type a callable taking a single object argument and returning an object. Some options:

 1) def map(fn as callable(object) as object, enumerable)

 2) def map(fn as (object)-&gt;object, enumerable)

 3) def map(fn as object-&gt;object, enumerable)

Thoughts?
