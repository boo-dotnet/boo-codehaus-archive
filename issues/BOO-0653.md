## Description

Reproduce:

Right click project, Add --&gt; New File.

Select class, name file "GoofedClass" but remove the ".boo" extension.

Click OK.

Rename file to have .boo extension (You weren't paying attention when you created it)

Spend several minutes baffling over why Boo cannot find the type "GoofedClass" even though it shows up in code completion, refactoring, and GoTo definition.

Finally investigate file properties and find that its set to "Content" instead of "Compile."

File JIRA issue over it.
