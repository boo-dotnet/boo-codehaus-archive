## Description

Triple double quotes aren't supposed to expand escape sequences, so the following line of code:

print """\$ \t \r \n 
""" # expecting - \$ \t \r \n 

Incorrectly returns:

$ \t \r \n 

See conversation here: http://groups.google.com/group/boolang/browse_thread/thread/8966c3704eef77f3
