## Description

As suggestedin BOO-1196, C#-style syntax is probably more elegant and more 'extensible' than the current [property|getter] AST attributes for automatic properties.

First it abstracts the underlying field thus promote better design (access property by the getter), secondly it just feels more natural and more consistent.

The additional features of [property|getter] could be implemented as standalone AST attributes (e.g [observable] applicable on property nodes).

```
MyProperty as string:
 get

```

generates (when concrete, the behavior for interface|abstract declarations do not change obviously) :

```
MyProperty as string:
 get:
 return _myProperty
_myProperty as string

```
