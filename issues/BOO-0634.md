## Description

This patch contains some helper / convienence properties and methods. It includes:

IsEmpty (is this List empty?)

First (returns first item in List)

Last (returns last item in List)

GetUniqueItems (get all the unique items in List)

operator | (Union, returns a List of unique items in rhs and lhs)
