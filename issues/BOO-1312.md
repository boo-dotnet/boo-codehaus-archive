## Description

When compiling Boo on .NET 4.0 with NAnt (Trunk/Alpha2), the booc.exe compiler will error out with a BadImageException. The attached diff seems to fix this exception but a MethodAccess Exception will pop up now. I believe that this exception is due to one of the many changes that occurred between 3.5 and 4.0. Attached is a detailed NAnt log with the MethodAccess exception (with verbose and debug turned on). Please let me know if more information is needed.
