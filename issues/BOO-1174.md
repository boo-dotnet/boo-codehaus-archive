## Description

The fact `is` is for reference/identity equality should not make it unusable on booleans against literal booleans for readability and python/ruby "compatibility" (wrt to new boo users).

```
"""
42
"""

x = true
if x is true: #currently issues: BCE0046: 'is' can't be used with a value type ('bool')
 print 42

```
