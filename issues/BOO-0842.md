## Description

Currently the code returned by a meta method cannot contain constructs that are supposed to have been taken care of before type resolution. Without reification it might be impossible for meta methods to return code that contains statement modifiers or macros for instance.

An idea would be to keep a reification action list in the compiler context. Every compilation step that needs to contribute to reification would add the appropriate action to the list after its execution so it can be called later to reify a code tree.
