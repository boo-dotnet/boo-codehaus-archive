I have implemented code completion for "self.", now only the resolver is missing.

But for this, the type system in the parsing step has to be changed dramatically.

At "compile" time, every file does not know about the other files or the referenced libraries. It should just parse and specify return types like "same return type as SomeOtherClass.OtherMethod()" or "HelloWorldClass, but I don't know in which namespace it is because I don't know my references". For this, the boo compiler pipeline has to be changed.
