The Boo IS repaired! Sure, the are features that strongly require implementation (mostly - generics). But the critical bugs are being quickly. You just need to provide a good test-case for it.

For this issue, I wasn't able to provide a test-case.... So I (with a great help of Rodrigo) set up the dev environment to build and debug Boo itself. The research showed first that there was an error in error reporting mechanism. It's hard to overestimate the importance of a proper error message... With patience Rodrigo helped me to find the exact place of the error and fixed it in a day. Once I had a proper error message, I was able to create 2 test-case for the 2 different BCE0055 cases that blocked me. Both were fixed in 24 hours...

In the conclusion, I'd like to say:

1. Boo IS good enough now (at least since the error reporting is correct).

2. If something is wrong, file a bug report and (optionally) draw the attention to it.

3. In most cases it will be fixed quickly.

About your problem:

1. Make sure that it's still there in Boo trunk.

2. Write to the mailing list again... Preferably with a small test-case.
