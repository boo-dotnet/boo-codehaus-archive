## Description

It looks like statement modifiers are ignored when we use parenthesisless methods.

Test case with 0.8.2:

&gt;&gt;&gt;def foo(a as string):

... print a

...

&gt;&gt;&gt;foo "blah"

blah

&gt;&gt;&gt;foo "blah" if 1 == 1

blah

&gt;&gt;&gt;foo "blah" if 1 == 2
