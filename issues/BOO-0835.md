## Description

Allow methods to be called with macro syntax for better composition, example:

callable Block()

def blockTag(tagName as string, block as Block):

 print "&lt;$
{tagName}&gt;"

 block()

 print "&lt;/${tagName}

&gt;"

def html(block as Block):

 blockTag "html", block

def body(block as Block):

 blockTag "body", block

def text(s as string):

 print s

html:

 body:

 text "Hello, world!"
