## Description

In:

```
def Foo[of T](t as T)
 x = cast(int, t)

```

The cast would be expanded as 

```
cast(int, cast(object, t))
```

 since a cast to object is necessary first.

If T has value-type constraint and the destination type is also a value type then the cast can be emitted directly.
