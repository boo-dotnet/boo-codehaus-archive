## Description

Ouch, just wasted some time because of this, I'm surprised we did not detect this bug earlier (except if it is a more or less recent regression somehow...)

Testcase:

```
"""
BCE0004-3.boo(12,4): BCE0004: Ambiguous reference 'Foo': BCE0004-3Module.Foo(System.ArgumentException), BCE0004-3Module.Foo(System.Exception).
BCE0004-3.boo(13,4): BCE0004: Ambiguous reference 'Foo': BCE0004-3Module.Foo(System.ArgumentException), BCE0004-3Module.Foo(System.Exception).
"""

def Foo(x as System.Exception):
 pass
def Foo(x as System.ArgumentException):
 pass

x as object = System.Exception()
Foo(x) #proper BCE0004
Foo(null) #BOO-1162 WAS: no error, chooses the last method definition!

```
