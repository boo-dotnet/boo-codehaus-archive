## Description

The last line of the following program causes an ICE. Workaround: replace the last line with a = f1; b += a

import System

class Example:

 def f1(o,e as EventArgs):

 pass

 a as EventHandler

 event b as EventHandler

 def this_causes_error():

 a = f1; b += a
