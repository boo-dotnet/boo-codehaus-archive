## Description

code:

interface ITest:

 def Test()

class TestClass(ITest):

 def Test():

 print "Test.Test"

 def ITest.Test():

 print "ITest.Test"

t as ITest = TestClass()

t.Test()

after compile: BCE0055: Internal compiler error: Object reference not set to an instance of an object..
