## Description

It might be nice if we had, in addition to the current

class A (B):

and

struct C (D):

if we had

attribute E (F):

This would simply translate into

class EAttribute (FAttribute):

However, if no inheritor is specified, it would inherit from System.Attribute, so

attribute E:

becomes

class EAttribute (System.Attribute):

This way, we wouldn't have to import System to declare an attribute, and then apply and declaring attributes would use the same names. What do you think?
