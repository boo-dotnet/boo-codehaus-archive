## Description

Allow setting "final" field values from the constructor, like C#'s "readonly".

This is useful for example in structs, where the fields cannot have their own initializers.

An example is below.

The fix is only a half line. In ProcessMethodBodies.AssertLValue, after EntityType.Field, change the if test to this:

if (TypeSystemServices.IsReadOnlyField((IField)entity)

 &amp;&amp; EntityType.Constructor != _currentMethod.EntityType)

struct Vector:

 final X as int

 final Y as int

 def constructor(x as int, y as int):

 X = x

 Y = y

s = Vector(1,2)

print s

This is the correct if block. I thought you could set a readonly field from a subclass too perhaps, but peverify says no. You can only set the value of a readonly field from a constructor in the same class the field resides in.

IField fld = (IField)entity;

if (TypeSystemServices.IsReadOnlyField(fld)

 &amp;&amp; !(EntityType.Constructor == _currentMethod.EntityType &amp;&amp;

 _currentMethod.DeclaringType == fld.DeclaringType &amp;&amp;

 fld.IsStatic == _currentMethod.IsStatic))
