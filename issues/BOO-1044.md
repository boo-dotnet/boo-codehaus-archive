Duplicate of BOO-1024.

Nullables have problems with implicit conversions on method parameters/return.

You can use this workaround meanwhile :

```

def ThisCompiles() as int?:
 ret as int? = 5
 return ret

thisWorks = ThisCompiles()+1

```
