## Description

"Error BCE0055: Internal compiler error: The type initializer for '&lt;Module&gt;' threw an exception."

Here is an example of the code creating the error:

---------------------------------------------------------------------------------------------

 public def TestSelection():

 db as Database = HostApplicationServices.WorkingDatabase

 ed as Editor = Autodesk.AutoCAD.ApplicationServices.Application.DocumentManager.MdiActiveDocument.Editor

 pso = PromptSelectionOptions()

 pso.MessageForAdding = '\nSelect objects:'

 result as PromptSelectionResult = ed.GetSelection(pso)

 if (result.Status != PromptStatus.OK) or (result.Status == PromptStatus.Cancel): //&lt;-----error here

 return

---------------------------------------------------------------------------------------------

The error seems to be when trying to compare the 2 enums (result.Stautus and PromptStatus.OK) where are the same type.

I'm trying to convert an old C# project and the only place I'm having trouble is with these autocad enums.

This compiles fine in C#/VBNet etc and is a very well used api for customising autocad.
