## Description

The following bad code:

"foobar".Split(1)

causes a BCE0023 compiler error, which contains a typo: "appropriate" mispelled as "apropriate"

BCE0023: Boo.Lang.Compiler.CompilerError: No apropriate version of 'System.String.Split' for the argument list '(System.Int32)' was found.
