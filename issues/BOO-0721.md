## Description

Consider the following code:

namespace CodeDomTest

import System

import System.Collections

import Boo.Lang.CodeDom

import Microsoft.CSharp

import System.CodeDom

import System.CodeDom.Compiler

providerCS = CSharpCodeProvider()

providerBoo = BooCodeProvider()

compileUnit = CodeCompileUnit()

namespace1 = CodeNamespace("TestNamespace")

compileUnit.Namespaces.Add( namespace1 )

// Creates a new type declaration.

newType = CodeTypeDeclaration("TestType")

// Sets the member attributes for the type to Public.

newType.Attributes = MemberAttributes.Public

namespace1.Types.Add(newType)

method1 = CodeMemberMethod()

method1.Name = "ReturnString"

method1.ReturnType = CodeTypeReference("System.String")

method1.Parameters.Add( CodeParameterDeclarationExpression("System.String", "text") )

// Create an initialization expression for a new array of type Int32 with 10 indices

ca1 = CodeArrayCreateExpression("System.Int32", 10)

// Declare an array of type Int32, using the CodeArrayCreateExpression ca1 as the initialization expression

cv1 = CodeVariableDeclarationStatement("System.Int32[]", "x", ca1)

method1.Statements.Add(cv1)

method1.Statements.Add( CodeMethodReturnStatement( CodeArgumentReferenceExpression("text") ) )

newType.Members.Add(method1)

gen as ICodeGenerator

gen = providerCS.CreateGenerator()

options = CodeGeneratorOptions()

using writer = System.IO.StreamWriter("""C:\Temp\CSCodeDom.cs"""):

 tw = IndentedTextWriter(writer, ' ')

 gen.GenerateCodeFromNamespace(namespace1, tw, options)

gen = providerBoo.CreateGenerator()

options = CodeGeneratorOptions()

using writer = System.IO.StreamWriter("""C:\Temp\BooCodeDom.boo"""):

 tw = IndentedTextWriter(writer, ' ')

 gen.GenerateCodeFromNamespace(namespace1, tw, options)

The C# output is:

namespace TestNamespace {

 public class TestType {

 private string ReturnString(string text) 
{
 int[] x = new int[10];
 return text;
 }

 }

}

The boo code is:

namespace TestNamespace

class TestType():

 private def ReturnString(text as string) as string:

 x as (int) = (of int: ,)

 return text

As near as I can tell the array length is always a comma (,) that indicates an empty array.
