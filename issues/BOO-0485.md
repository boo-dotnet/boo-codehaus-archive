## Description

Currently, the parser accepts only integer literals as enum values. Boo should be able to use any constant integer expression like C#:

import System

enum Test:

 A = 1

 B = TWO

 C = 4

 D = A

 ALL = A | B | C

final TWO = 2

print Test.ALL
