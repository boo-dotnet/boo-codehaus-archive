## Description

For enum types, in c# you can type:

enumVar++;

while in boo you have to:

enumVar = cast(EnumType, cast(int, enumVar)+1)

In src/boo.lang.compiler/typesystem/typesystemservices.cs, add this to the end of the IsIntegerNumber method around line 682:

 type.IsEnum;

And that appears to allow this and other things to work like in C#, but I haven't tested it much. I only used the below test:

import System

[Flags]

enum Attributes:

 A = 0

 B = 1

 C = 2

 D = 4

enum Days:

 Sun

 Mon

 Tue

 Wed

 Thu

 Fri

 Sat

val = Days.Tue

val++

print val //Wed

atts = Attributes.C | Attributes.D

print atts //C,D

atts++

print atts //B,C,D

atts = 4

print atts //D
