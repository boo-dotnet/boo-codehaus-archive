## Description

Remove the need for extra "end" statements after get and set for properties in wsa mode. See example at bottom.

One way to do this is in interface_property_accessor rule of wsaboo.g, change

 eos | empty_block[m]

to

 (begin)? eos

and in property_accessor rule change:

 compound_stmt[body]

to

 begin block[body.Statements]

//////////////////////////

interface ITest:

 X:

 get

 set

 end

end

interface ITest2:

 X:

 get:

 end //&lt;--remove

 set:

 end //&lt;--remove

 end

end

class C(ITest):

 X:

 get:

 print "getting"

 return 4

 end //&lt;--remove

 set:

 print "setting"

 end //&lt;--remove

 end

end

c = C()

print c.X

c.X = 0

I have other modifications too if ever wanted. Such as allowing for an optional identifier after the "end" statement to provide stricter checking that you are ending the correct block: "end class" "end if" etc. If you write "end def" when you meant "end class" it will catch that. Also I have wsa mode working with no colons required.
