## Description

With literal array of a primitive number type, such as:

```
arr = (of byte: 1, 2, 3, 4, 256)

```

The compiler should force the type of every item integer literal as `byte' instead of `int' (to avoid casting at run-time).

Additionally all literals (as well as 'folded' literals) should be range-checked and an error issued when one value is out of range of array/destination type (that would fail at run-time).

For above array initialization:

```
BCExxxx: Constant value `256' cannot be converted to a `byte'

```

But also:

```
def Foo(x as byte):
 pass

Foo(256) #BCExxxx: Constant value `256' cannot be converted to a `byte'

```

```
x as byte = 256 #BCExxxx: Constant value `256' cannot be converted to a `byte'

```
