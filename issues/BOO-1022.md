## Description

Currently the compiler will compile the following as a library without displaying any error/warning :

```
def foo():
 return 42

print "initialized"

```

It will create a Main() method whereas it obviously makes no sense for a library.

A more sensible default would be to put "main block" inside the static constructor of the module.

NB: Investigate using System.Runtime.CompilerServices.RuntimeHelpers.RunClassConstructor() to offer deterministic initialization order
