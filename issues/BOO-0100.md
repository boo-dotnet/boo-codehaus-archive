## Description

Generators should be able to modify their enclosing environment:

&lt;test&gt;

import NUnit.Framework

i = 0

g = (++i)*j for j in range(3)

Assert.AreEqual("0 2 6", join(g))

Assert.AreEqual(3, i)

&lt;/test&gt;
