## Description

A couple of improvements to the UsingMacro:

 1. consistently assign ref to null for both assignment and non-assignment expressions

 2. support multiple expressions in 'using' instead of just one

1. The current version of the using macro sets the provided reference to null only if an assigment expression is used. 

For example:

===

using reader=File.OpenText("foo.txt"):
