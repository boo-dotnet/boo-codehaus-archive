## Description

A couple of improvements to the UsingMacro:

 1. consistently assign ref to null for both assignment and non-assignment expressions

 2. support multiple expressions in 'using' instead of just one

1. The current version of the using macro sets the provided reference to null only if an assigment expression is used. 

For example:

===

using reader=File.OpenText("foo.txt"):

 print(reader.ReadLine())

===

expands to:

=== 

public final transient class Bt1Module(System.Object):

 private static def _Main_(argv as (System.String)) as System.Void:

 try:

 reader = File.OpenText('foo.txt')

 Boo.Lang.Builtins.print(reader.ReadLine())

 ensure:

 if (_disposable_ = (reader as System.IDisposable)):

 _disposable_.Dispose()

 _disposable_ = null

 reader = null

 private def constructor():

 super()

===

However:

===

reader=File.OpenText("foo.txt")

using reader:

 print(reader.ReadLine())

===

expands to:

=== 

public final transient class Bt1Module(System.Object):

 private static def _Main_(argv as (System.String)) as System.Void:

 reader = File.OpenText('foo.txt')

 try:

 _using1_ = reader

 Boo.Lang.Builtins.print(reader.ReadLine())

 ensure:

 if (_disposable_ = (_using1_ as System.IDisposable)):

 _disposable_.Dispose()

 _disposable_ = null

 _using1_ = null

 private def constructor():

 super()

===

In the 2nd case, 'reader' is left referencing a disposed object.

Suggested improvement, expand the using so that non-assignment expressions also set the reference to null:

===

public final transient class Bt1Module(System.Object):

 private static def _Main_(argv as (System.String)) as System.Void:

 reader = File.OpenText('foo.txt')

 try:

 Boo.Lang.Builtins.print(reader.ReadLine())

 ensure:

 if (_disposable_ = (reader as System.IDisposable)):

 _disposable_.Dispose()

 _disposable_ = null

 reader = null

 private def constructor():

 super()

===

2. The current version of the using macro throws a NotImplementedException if more than 1 expression is provided.

For example:

===

reader=File.OpenText("foo.txt")

using reader, reader2=File.OpenText("foo2.txt"):

 print(reader.ReadLine())

 print(reader2.ReadLine())

===

Suggested improvement, support multiple expressions:

===

public final transient class Bt1Module(System.Object):

 private static def _Main_(argv as (System.String)) as System.Void:

 reader = File.OpenText('foo.txt')

 try:

 reader2 = File.OpenText('foo2.txt')

 Boo.Lang.Builtins.print(reader.ReadLine())

 Boo.Lang.Builtins.print(reader2.ReadLine())

 ensure:

 if (_disposable_ = (reader as System.IDisposable)):

 _disposable_.Dispose()

 _disposable_ = null

 reader = null

 if (_disposable_ = (reader2 as System.IDisposable)):

 _disposable_.Dispose()

 _disposable_ = null

 reader2 = null

 private def constructor():

 super()

===
