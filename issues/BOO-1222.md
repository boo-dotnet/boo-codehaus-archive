## Description

This would make the AST easier to work with when doing numeric processing/conversions.

This also opens the possibility for automatically supporting new custom numeric literals such as complex numbers, units, and other things that will be possible with the extensible parser.

```
class NumericLiteralExpression (LiteralExpression):
 GetValueAs&lt;T&gt;() as T

```
