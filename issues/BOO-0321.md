## Description

BooBinding is broken since a recent SVN update included "OnCharLiteralExpression" to Boo's CodeDom; since BooBinding's CodeDomVisitor class fails to implement this it is marked as abstract and thus cannot be instanized; compiling is impossible.

Requires adding empty "OnCharLiteralExpression" method to get functioning BooBinding.
