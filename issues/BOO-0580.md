## Description

Allow the "isa" operator to work with variables.

Then one could write something like this:

Only the following types are supported by BEncoding.

validTypes = [

........sbyte,

........byte,

........char,

........short,

........ushort,

........int,

........uint,

........long,

........ulong,

........IList,

........IDictionary,

........typeof((byte))]

list = [1, 2, 3, 4]

unless len(List(type for type as Type in validTypes if list isa type)) &gt; 0:

........raise NotSupportedException(

................string.Format(

........................ExceptionMessages.NotSupportedException_Type,

........................itemType))

NOTE: "unless validTypes.Contains(list.GetType())" does not work because GetType() returns List, not IList.
