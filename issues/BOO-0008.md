## Description

The parser should accept the extend syntax:

 import &lt;IDENTIFIER&gt; from &lt;DOUBLE QUOTED STRING&gt;

which would give better support for "weird" named assemblies such as gtk-sharp:

 import Gtk from "gtk-sharp"

## Comments (1)

---

### Rodrigo B. de Oliveira, 15/Jul/04 8:09 PM

the final syntax is:

 import identifier from (identifier | SingleQuotedString | DoubleQuotedString)

allowing:

import Gtk from "gtk-sharp"

as well as

import Gtk from 'gtk-sharp'
