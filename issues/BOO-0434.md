## Description

Attached is an adorable little duck called ResourceFu that lets you kung-fu your way to victory by getting resources from an assembly dynamically. 

Also, its better than Ayende's because I said so and put my name on it. 

resources = Useful.Fu.ResourceFu('MyResources')

text = resources.DialogPromptResource as string

print text

Etc.
