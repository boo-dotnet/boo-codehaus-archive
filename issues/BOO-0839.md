## Description

How about maintaining a docbook-based documentation file on the repository ?

Then we can easily use oss tools who generates HTML, PDF, or even man files to better package the documenation both locally and on the web.

NAnt could generate an updated PDF for inclusion in the distribution packages (deb/msi/dmg) each time we make a new release
