## Description

We've been discussing some possible syntaxes for closures but I'd like to gather some more opinions on this matter.

The new syntax must blend in with the current syntactic framework. Some of the values that have been driving the design are simplicity, terseness, python-likeness 

I'd rather avoid introducing new keywords if possible.

The syntax should ideally allow ruby-like block to method passing.

The current candidate syntax reuses the callable keyword:

anonymous method with a single parameter

button.Click += callable(sender):

 print("$
{sender}

 was clicked!")

no parameters

button.Click += callable:

 print("clicked!")
