## Description

```
"""
Foo
"""

class A[of T]:
 internal def Foo():
 print "Foo"

class B:
 def Bar():
 A[of int]().Foo()

b = B()
b.Bar()

```

test.boo(11,21): BCE0120: Boo.Lang.Compiler.CompilerError: 'A[of T][int].Foo' is inaccessible due to its protection level.

Probably related to not handling IConstructedXInfo as in BOO-1079.
