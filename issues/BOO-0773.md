## Description

While converting a C# file to boo, a switch statement was transformed into a series of if-then-else constructs. The switch had gotos, and two of the labels created for the gotos contained negative numbers, which led to syntax errors. Here is a illustrative snippet:

...

 goto converterGeneratedName3_-1220620082

 else:

 if converterGeneratedName3 == s_MouseDown:

 :converterGeneratedName3_-1220620082

...
