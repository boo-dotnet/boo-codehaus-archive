## Description

I made this small patch for binary integer literals, similar to those in Python 2.6+. E.g.

i = 0b1010101110

They are implemented almost exactly like hex digits, e.g. you can specify l or L at the end to make them explictly of type long, otherwise they will be int if possible, long if larger than int.maxvalue.
