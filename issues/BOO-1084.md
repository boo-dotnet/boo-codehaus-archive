## Description

When a class implementing IQuackFu has an indexer, QuackGet is invoked instead of explicitely declared indexer.

Testcase :

```
class Foo (IQuackFu):
 def Bar():
 return "Bar"

 self[s as string]:
 get: return s

f = Foo()
print Bar() #prints Bar
print f["Indexer"] #! crashes (since it calls QuackGet) instead of using the declared indexer.

```
