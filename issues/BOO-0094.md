## Description

ruby-like true closures (http://www.artima.com/intv/closures2.html).

&lt;testcase&gt;

def each(items, action as callable(item)):

 for item in items:

 action(item)

i = 0

each(range(4)) do (x as int):

 i += x

Assert.AreEqual(6, i)
