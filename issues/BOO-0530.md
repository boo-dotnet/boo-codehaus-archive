### Doug H, 20/Oct/05 10:32 PM

I could make it work by adding small xml config files for booi.exe and booc.exe. Using .net 2 release candidate (I don't have the .net 2 sdk, and I didn't rebuild boo at all). If you are using .net 2 beta 2 instead of the release candidate, try a version number like v2.0.40607 instead of v2.0.50727.

&lt;?xml version="1.0"?&gt;

&lt;configuration&gt;

 &lt;startup&gt;

 &lt;supportedRuntime version="v2.0.50727" /&gt;

 &lt;!-- supportedRuntime version="v1.1.4322" --&gt;

 &lt;/startup&gt;

&lt;/configuration&gt;
