## Description

Given method in some class:

public class A {

 public T call&lt;T&gt;(Func&lt;T&gt; innercall)
{ return innercall();}

}

Given Boo call:

x = A().call(
{'test'})

In 0.9.1 version all of generics was resolved, and treated as:

x as string = A().call[of string]({'test'}

)

But on 0.9.4 (maybe on 0.9.3 too, I haven't use it) it cause a compiler error:

"Cannot find overload for ... call ... with parameters (error)..."

If I change code to

x = A().call[of string](
{'test'}

)

all works well

Test fixture provided in file.

There are two tests - first is fail for now and show problem, second show avoid and is "green" for now.
