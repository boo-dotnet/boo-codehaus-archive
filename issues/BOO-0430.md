## Description

A rudimentary AST attribute, for inclusion on Boo.Lang.Useful.

It'll generate delegating members from a field. It's quite simple, but works for simple cases.

### Doug H, 10/Aug/05 3:13 PM

The hangup with ImplementsAttribute is that you have to know the type of the thing you are wrapping. For example to fetch all the methods/properties, retrieve information about the right parameters for each method, etc. At the time that AST attributes are processed in the compiler pipeline, none of that type information is available yet.

But there are ways to work around this by using the AfterStep event so that the macro can do processing later on in the pipeline after type information is available.

### F�bio Batista, 10/Aug/05 11:32 AM

Sometimes you need to delegate members of an aggregated class. Take Thread as an example:

class Worker:

 t as Thread

 def constructor():

 t = Thread(Run)

 def Start():

 t.Start()

 def Stop():

 t.Stop()

 def Pause():

 t.Pause()

 def Run()

 while true:

 print "tic"

 Thread.Sleep(10s)

Using the [delegate] attribute, it's way simpler:

class Worker:

 [delegate(Start, Stop, Pause)] t as Thread

 def constructor():

 t = Thread(Run)

 def Run():

 while true:

 print "tic"

 Thread.Sleep(10s)
