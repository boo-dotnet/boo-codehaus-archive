## Description

The boo compiler currently does not allow constants to be declared in any scope other than class member definition scope. ToDo: Make amends to the boo compiler to allow declaration of constants in the global scope, local scope of functions/methods etc. Also please consider using the "const" keyword as is used in C++/C# and numerous other languages. IMHO "const" specifies the intent better than "final". I think "Final" should only be used to declare final classes.
