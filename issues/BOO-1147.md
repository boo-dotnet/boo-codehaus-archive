## Description

Given a C# class:

public abstract class Foo&lt;ObjectType&gt;

where ObjectType : Foo&lt;ObjectType&gt;

{

}

Used in Boo as:

class Bar(Foo[of Bar]):

pass

I get the compiler error "Node 'Foo[of Bar]' has not been correctly processed. (BCE0015)"

A real-world example of this would be the CSObject[of T] in the CoolStorage ORM.
