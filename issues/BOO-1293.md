## Description

Attribute (in a separate module):

```
AttributeUsage(AttributeTargets.Method)]
public class Method(AbstractAstAttribute):
 public def constructor(*types as (Ast.ReferenceExpression)):
 pass

```

Application:

```
[ext.spec.Method(byte,short,single)]
public def read[of T(struct)](ar as (T)) as void:
 pass

```

Error: BCE0009: An error occurred during the resolution of the 'ext.spec.Method' ast attribute: 'parameters do not match signature'. (engine)
