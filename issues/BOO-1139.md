## Description

```
"""
Hello
"""
def Using[of T(System.IDisposable)](value as T, block as callable(T)):
 try:
 block(value)
 ensure:
 value.Dispose()
 
Using(System.IO.StringReader("Hello"), { reader | print reader.ReadLine() })

```

If the parameter type is changed to System.Action[of T] it's all good.
