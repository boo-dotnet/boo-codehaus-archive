## Description

Current CLR supports:

covariance for generic reference types parameters of generic interface types. Generic parameter 'alone' can be used as a method return type only.
 
contravariance for generic reference types parameters of generic interface types. Generic parameter 'alone' can be used as method by-value argument type only.

Syntax-wise we introduce "in" and "out" keywords in constraint declaration context so that declaring a variant generic parameters is similar to C# 4.0 (e.g 

```
IFoo[of T(out)]
```

).

Using 'in' or 'out' implies 'class' constraint.

Testcase (covariance-1.boo):

```
"""
OK
"""
class Base:
 pass
class Derived (Base):
 pass

interface IFoo[of T(out)] : #BCE0xxx with 'out' when typedef is not an interface.
 pass

class Foo[of T] (IFoo[of T]):
 pass

def Method(x as IFoo[of Base]):
 print "OK"

f = Foo[of Derived]()
Method(f)

```
