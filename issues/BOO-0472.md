It's an antlr issue. If your file is utf-8 encoded, your code will work.

To convert a file to utf-8 in jedit, select utilities-&gt;buffer options-&gt;encoding-&gt;utf-8.

Probably the compiler should convert input files or strings to utf-8 encoding if necessary before passing them on to antlr.
