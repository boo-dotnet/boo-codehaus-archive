## Description

&gt;&gt;&gt; char('a') - char('A')

--------------^

ERROR: Operator '-' cannot be used with a left hand side of type 'char' and a right hand side of type 'char'.

I don't think it makes much sense to add 2 characters together, but it does make sense to add integers to characters, as in

char('q') + 1 == char('r')

and

char('q') + (char('A') - char('a')) == char('Q')

so I'm thinking the result of subtracting two characters should be a ushort.
