## Description

```
"""
23
42
"""
class Test:
 _value as double?

 Value as double:
 get: return _value
 set: _value = value

 def GetMethod() as double:
 return _value

 def constructor(value as double):
 _value = value

t = Test(23)
print t.Value 
t.Value = 42
print t.GetValue()

```
