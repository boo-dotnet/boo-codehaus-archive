## Description

Hello I have encountered a bug which occurs with latest svn (2799) as well as the GO branch. However this bug does not exist in 0.7.8.2559.

Here's the test case:

///A.boo

class A:

 pass

///B.boo

import System.Collections.Generic

class B:

 a as List of A = List of A()

compiling this with svn head or GO gives the following error:

(./booc.exe:21634): WARNING **: Missing method Boo.Lang.Compiler.TypeSystem.ITypedEntity.get_Type in assembly /home/onur/tmp/boo/go/generics-overloads/build/Boo.Lang.Compiler.dll token 60011ec

B.boo(4,31): BCE0055: Internal compiler error: A type load exception has occurred..

1 error(s).

However when I alter the B class as below it works :

class B:

 a as List of int = List of int()

It seems only Boo coded classes causes this problem.

Also there is no such problem with 0.7.8.2559
