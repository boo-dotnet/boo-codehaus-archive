## Description

The following program compiles contains four cases that show that BCW0006 is rarely behaving as expected.

It works correctly for simple properties - the warning is only used for readonly properties when the assigned value cannot be written back.

The text of the warning should be changed to make clear that the assigned value will not be saved.

struct MyStructure:

 Field as int

class HelperClass:

 [property(P), getter(ReadOnly)]

 field as MyStructure

 self[index as int]:

 get:

 return field

 set:

 field = value

// .locals init ([0] MyStructure[] structureArray1)

arr = array(MyStructure, 100)

// L_0000: ldc.i4 100

// L_0005: newarr MyStructure

// L_000a: stloc.0 

arr[10].Field = 5 // BCW0006: WARNING: Assignment to temporary.

// L_000c: ldloc.0 

// L_000d: ldc.i4 10

// L_0012: ldelema MyStructure // gets reference to element in array

// L_0017: ldc.i4 5

// L_001c: stfld int32 MyStructure::Field

// Boo correctly set the field directly in the array. BUG 1: the warning should not be displayed in this case.

print arr[10].Field // correctly prints 5

//----------------------------------------

h = HelperClass()

h.P.Field = 6 // this does NOT display a warning

print h.P.Field // this prints 6: everything worked correctly here

//----------------------------------------

h[20].Field = 7 // since there is a setter for this indexer, no need for a warning

print h[20].Field // this does print 6, but should print 7!

// BUG 2: this went wrong - it should work like the property above

//----------------------------------------

h.ReadOnly.Field = 8 // this correctly displays the warning

print h.ReadOnly.Field // and correctly displays the previous value

// in case of readonly properties, Boo cannot save the value. ONLY here the warning should be used, and the text should be changed to make clear that the value cannot be stored
