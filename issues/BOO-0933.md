## Description

Testcase :

```
import System

class MyClass:
 def constructor(foo as string, bar as int):
 pass

args = array(object, 2)
args[0] = "foo"
args[1] = 42
try:
 Activator.CreateInstance(typeof(MyClass), args) # fails
except e:
 print e
Activator.CreateInstance(typeof(MyClass), args[0], args[1]) # works if using 'expanded' syntax
Activator.CreateInstance(typeof(MyClass), args, null) # works when using an overload with another arg at the end
print "ended"

```

The first call to Activator.CreateInstance fails with MissingMethodException because it actually passes the args array into another englobing array.

I suspect the problem lies in ExpandVarArgsInvocation but I haven't investigated yet.

Or should I have used some syntax in order to do this ??
