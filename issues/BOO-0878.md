## Description

This currently compiles, but the second catch block is unreachable

```
try:
 raise SomeException()
except ex as Exception:
 print "Smokescreen"
except ex as SomeException:
 pass "The real deal"

```

The compiler should detect this and issue a compiler error/warning for the unreachable except block.
