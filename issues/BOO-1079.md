## Description

```
"""Hello"""

class B(A[of string]):
 
 def Foo():
 return Bar()

class A[of T]:
 def Bar():
 return "Hello"

b = B()
print b.Bar()

```

Results in compiler error:

BCE0011: Boo.Lang.Compiler.CompilerError: An error occurred during the execution of the step 'Boo.Lang.Compiler.Steps.Em

itAssembly': 'Could not find a Type for unknown.'. ---&gt; System.InvalidOperationException: Could not find a Type for unkn

own.

 at Boo.Lang.Compiler.Steps.EmitAssembly.GetSystemType(IType tag)

 at Boo.Lang.Compiler.Steps.EmitAssembly.DefineMethod(TypeBuilder typeBuilder, Method method, MethodAttributes attribu

tes)

 at Boo.Lang.Compiler.Steps.EmitAssembly.DefineTypeMembers(TypeDefinition typeDefinition)

 at Boo.Lang.Compiler.Steps.EmitAssembly.DefineTypes()

 at Boo.Lang.Compiler.Steps.EmitAssembly.Run()

 at Boo.Lang.Compiler.CompilerPipeline.RunStep(CompilerContext context, ICompilerStep step)

 — End of inner exception stack trace —

If A is moved above B, then it compiles fine.

Similar to the first report in BOO-935 but it involves inheritance instead of constraints.
