## Description

Testcase:

```
#static case
s = "foo"
string_isNullOrEmpty = Type.GetType("System.String").GetMethod("IsNullOrEmpty", BindingFlags.Public | BindingFlags.Static)
assert not string_isNullOrEmpty(s)

#instance case
string_length = Type.GetType("System.String").GetProperty("Length").GetGetMethod()
assert string_length(s) == 3

```
