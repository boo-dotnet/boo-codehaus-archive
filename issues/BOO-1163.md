## Description

Windows api calls require particular data structures. The addition of a flag changes these structures. I'm now getting invalid results placed in my ManagedRect class when calling the api function GetWindowPlacement(). Perhaps the compiler can be made to not add this initialization flag if StructLayoutAttribute is applied...

The following class:

```
[StructLayout(LayoutKind.Sequential)]
private class ManagedRect:
 public x = 0
 public y = 0
 public right = 0
 public bottom = 0

 public def constructor():
 pass

 public def constructor(x as int, y as int, right as int, bottom as int):
 self.x = x
 self.y = y
 self.right = right
 self.bottom = bottom
```

Disassembly of Boo 0.8 version:

```
[Serializable, StructLayout(LayoutKind.Sequential)]
private class ManagedRect
{
 public int x;
 public int y;
 public int right;
 public int bottom;
 public ManagedRect()
 {
 this.$initializer$();
 }

 public ManagedRect(int x, int y, int right, int bottom)
 {
 this.$initializer$();
 this.x = x;
 this.y = y;
 this.right = right;
 this.bottom = bottom;
 }

 /* private scope */ void $initializer$()
 {
 this.x = 0;
 this.y = 0;
 this.right = 0;
 this.bottom = 0;
 }
}
```
