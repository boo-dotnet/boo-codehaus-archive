## Description

```
import System

struct A(IEquatable[of A]):
 
 _data as int
 
 def Equals(other as A):
 return _data == other._data

a = A()
b as IEquatable[of A] = A()
x as IEquatable[of A] = null

assert not a.Equals(x)
assert not b.Equals(x)

```

Both assertions fail above, whereas a == x and b == x work fine. Apparently the operator calls go through Boo.Lang.Runtime.RuntimeServices and are handled correctly, but a.Equals and b.Equals remain unchanged. It could be caused by the .net framework itself.
