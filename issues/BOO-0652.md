## Description

Summary: Method names used in System.Object should not be allowed as function names in modules.

Boo actually allowed me to do this (I wasn't paying attention when I wrote this particular block of code)

namespace blahblah

def ToString(input): #You, my friend, caused me a lot of trouble, you know that?

 return "Boooo!"

Somewhere in my code I imported the blahblah namespace, doing some heavy reflection-based stuff, and was keeping a reference of ToString in a list. When I pulled ToString out of the list, cast it as a callable object, and tried to execute it on an object, what happened was that it actually called the ToString() method of the object I had passed as input, rather than my ToString method. Changing to anonymous closures fixed it, of course, so would have renaming it, but Boo should have given me a warning or error in the first place. 

The actual code is available, but its hard to understand without seeing the whole project. Be you curious, my friend, and I will serve up the relevant chunks, though.
