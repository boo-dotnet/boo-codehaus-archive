## Description

Stuart Rackham wrote:

I've attached a patch for consideration, it enhances the

booc response file processing (similar to MS csc):

Response files can contain both options and source file

 names.
 
Lines beginning with a hash character are skipped.
 
Response files can be nested.
 
An optional default response file in the booc.exe

 directory named booc.rsp will be automatically included

 (unless explicitly excluded with the -noconfig option).
 
Arguments are processed in the order they occur, the

 default response file is processed first.
 
One option or source file name per line.
