## Description

I'd like to be able to have static variables in methods:

def method() as int:

 static x as int = 0

 if x == 0: // x not cached yet?

 &lt;do some huge long calculation of x&gt;

 return x

I know I could make x a static class field... but why shouldn't boo do that for me? Also, there's no way to make a static class field at module level since defs come before vars.
