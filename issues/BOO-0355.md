## Description

The compiler does not reference Boo.Lang.Useful by default, which means doing this:

import Useful.IO from "Boo.Lang.Useful"

Which is, sincerely, a pain in the ass after the third or fourth time.

### Arron Washington, 07/Jun/05 10:07 PM

Nonono. See, .NET in general prolongs loading until you use something from a referenced library.

Thus, this application:

import Boo.Lang.Useful.IO from "Boo.Lang.Useful"

print "LOL!"

works perfectly if you do not XCOPY Boo.Lang.Useful.dll with deployment.

So there's really no reason not to reference Useful by default, unless you have another thing?

### Peter Johanson, 07/Jun/05 10:02 PM

I think there's a reason that these things are in Boo.Lang.Useful. They are useful things, but by no means needed. Having all things compiled reference .Useful when they are completely unneeded is a bad thing, imho
