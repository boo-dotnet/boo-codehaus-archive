## Description

Whenever a constructor already exists or not Boo always add a private default constructor to a class with [CompilerGlobalScope].

This is blocking for using only Boo in a ASP.NET project as the CodeDom-generated global.asax has such a class with a default constructor.

This should be allowed:

```
"""
OK
"""

[System.Runtime.CompilerServices.CompilerGlobalScope]
class Test:
 def constructor():
 print "OK"

Test()

```
