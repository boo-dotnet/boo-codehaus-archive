## Description

Currently errors with these types look ugly :

```
&gt;&gt;&gt;x as int?
&gt;&gt;&gt;y as date?
&gt;&gt;&gt;x = y
--------^
ERROR: Cannot convert 'System.Nullable`1[[System.DateTime, mscorlib, Version=2.0.0.0, Culture=neutral, PublicKeyToken=b77a5c561934e089]]' to 'System.Nullable`1[[System.Int32, mscorlib, Version=2.0.0.0, Culture=neutral, PublicKeyToken=b77a5c561934e089]]'.
&gt;&gt;&gt;e as int* 
&gt;&gt;&gt;e = y 
------^
ERROR: Cannot convert 'System.DateTime' to 'System.Collections.Generic.IEnumerable`1[[System.Int32, mscorlib, Version=2.0.0.0, Culture=neutral, PublicKeyToken=b77a5c561934e089]]'.

```

Should be :

```
ERROR: Cannot convert 'date?' to 'int?'
ERROR: Cannot convert 'date?' to 'int*'

```
