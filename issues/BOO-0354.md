## Description

As promised, hereby an implementation of the CacheAttribute. 

This is a replacement of the MemoizeAttribute. The CacheAttribute needs the Boo.Lang.Useful.Collections.Cache class (http://jira.codehaus.org/browse/BOO-352).

(for compilation add an extra "s" to the namespace of the Cache class).

I also enclosed a CacheAttributeFixture

Usage:

[Cache(3)]

def adder(i as int):

 return i+1

caches the last 3 different calls made to the function adder
