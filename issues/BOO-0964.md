## Description

```
 
"""
hello from X !
hello from Y !
hello from Z !
"""
import System.Diagnostics

def X():
def Y():
def Z():
 print "hello from ${StackTrace(true).GetFrame(1).GetMethod().Name} !"

X()
Y()
Z()

```

the methods must have compatible signature (except name of course) or an error is issued.

compiler generates a method whose call will be the body of the nested method definitions (call+ret if method is not void).
