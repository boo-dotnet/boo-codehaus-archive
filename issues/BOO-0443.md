## Description

sz = Size()

sz.Height

Using the initobj opcode instead of newobj opcode, like C#:

using System;

using System.Drawing;

namespace csharp

{

 class MainClass

 {

 public static void Main(string[] args)
 {
 Size sz = new Size();
 sz.Height = 100;
 System.Console.WriteLine(sz);
 
 Point pt = new Point();
 pt.X = 3;
 System.Console.WriteLine(pt);
 }

 }

}
