## Description

Feature complete with code literals, splicing and the 'macro' macro.

```
macro performTransaction:
 args = performTransaction.Arguments
 return [|
 _transaction = $(args[0]).BeginTransaction()
 try:
 $(performTransaction.Block)
 _transaction.Commit()
 except:
 _transaction.Revert()
 raise
 ensure:
 _transaction.End()
 |]

```
