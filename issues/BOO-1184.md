## Description

It would be cool, if it's was possible to declare a meta-method to be used as an extension method:

So for example, to execute a method for all items of one list, we could use it something like this:

List = ["foo", "bar"]

ToUpperList = List.forall(ToUpper)

The meta method implementation could be something like this:

[meta][extension] 

def forall(this as List, thisReferece as Expression, method as ReferenceExpression):

 return [| x.$(method)() for x in $thisReference |]
