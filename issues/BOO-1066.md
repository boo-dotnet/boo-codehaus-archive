## Description

When I run the code 

x= 1.0 

print 2.718281828*(- x*2) 

on Boo, I get 2.718281828. It looks like not only x, but -x is taken to the power of 2. 

On both CPython and IronPython the same code gives me correct result 0.367879441234.
