## Description

Here's valid C# code:

```
interface ISerializable 
{ 
 byte[] Serialize(object o); 
 object Deserialize(byte[] bs, int start); 
} 
 
interface ISerializable&lt;T&gt; : ISerializable 
{ 
 byte[] Serialize(T o); 
 new T Deserialize(byte[] bs, int start); 
} 
 
class StringSerializer : ISerializable&lt;string&gt; 
{ 
 public byte[] Serialize(object o) 
 { return null; } 
 
 public byte[] Serialize(string o) 
 { return null; } 
 
 public string Deserialize(byte[] bs, int start) 
 { return null; } 
}
```

Interfaces dont appear to support a "new" key in Boo. This is the closest I could get in Boo:

```
interface ISerializable:
 def Serialize(object) as (byte)
 def Deserialize( bs as (byte), int) as object

interface ISerializable[of T] (ISerializable):
 def Serialize(T) as (byte)
 def Deserialize( bs as (byte), int) as T

class StringSerializer (ISerializable[of string]):
 def Serialize(o as object) as (byte):
 return null
 def Serialize(o as string) as (byte):
 return null
 def Deserialize(bs as (byte), start as int) as string:
 return null
```
