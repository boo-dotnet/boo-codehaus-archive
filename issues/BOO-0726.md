## Description

When trying to run the following program:

```
def Main():
 print "Ok"

```

it fails with the following exception stack:

```
Unhandled Exception: System.Reflection.TargetParameterCountException: Parameter count mismatch.
 at System.Reflection.RuntimeMethodInfo.Invoke(Object obj, BindingFlags invokeAttr, Binder binder, Object[] parameters, CultureInfo culture, Boolean skipVisibilityChecks)
 at System.Reflection.RuntimeMethodInfo.Invoke(Object obj, BindingFlags invokeAttr, Binder binder, Object[] parameters, CultureInfo culture)
 at System.Reflection.MethodBase.Invoke(Object obj, Object[] parameters)
 at BooiModule.Main(String[] argv)

```

I believe there should be a check for signature of entry point, i.e. if it contains parameters, and it shouldn't pass arguments if signature does not have any.
