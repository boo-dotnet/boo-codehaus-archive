## Description

#develop doesn't do CC / etc for variable scope in the following situation:

if true:

 var = "hello"

var #no autocomplete, code info, etc.

This is valid in Boo; any variables declared in a conditional block are visible outside of the block. ... I think its valid for all blocks inside of a method, actually.
