## Description

Let's make Boo support new .NET 4.0's DynamicObject ( http://msdn.microsoft.com/en-us/library/system.dynamic.dynamicobject_members%28VS.100%29.aspx ).

As it supersedes current Boo's IQuackFu in functionality moreover providing interop with other CLR languages I suggest we issue an "Obsolete" warning when IQuackFu is used when compiling on 4.0 target.

PS: I would dare to mark this a 1.0 feature, if only 1.0 was in the fix versions lists (Rodrigo?)
