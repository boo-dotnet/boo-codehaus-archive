## Description

Exceptions derive from ISerializable, so they have to implement serialization manually. CompilerError doesn't override GetObjectData or provide a protected serialization constructor like it should.

Noticed this when using Binsor, so the DLLs might be old, but the SVN head revision still has the problem.
