## Description

"assert node isa ClassDefinition" fails if one does not want structures.

Boo currently allows for 2 ways to define structures.

struct Foo:

 pass

class Foo(ValueType):

 pass

It is odd that even if a structure is declared with the keyword struct, it is still picked up as a ClassDefinition.

Disallow, the derivation of classes from ValueType and force the use of the struct keyword. Fix the AST to pick up StructDefinition properly.
