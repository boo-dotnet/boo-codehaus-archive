Looks good to us. Both of these work in the interpreter:

&gt;&gt;&gt;print((1 if 1 == 2 else 3 ))

3

---

### Cedric Vivier, 17/Apr/08 9:13 AM

print being an optional-parenthesis builtin, It works only if you use print((1 if 1 == 2 else 3 )) to disambiguate between ternary and method call parenthesis.

---

### Gareth Farrington, 12/Oct/07 9:40 AM

This issue is affecting those of us using Brail as a templating language in Monorail. As you can imagine its nice to have a short hand alternative for if/else in a templating language. It broke a lot of existing code and forced us to make several changes to use the new version of Boo.

We looked briefly at hacking this back in as a macro but we cant because all the macro args are evaluated before the macro is called. There is just no replacement for a ternary operator.
