## Description

The Boo compiler do not resolve a calling to an extension method that has self as target:

Ex:

import FooExtension

class Foo:

 def Bar():

 Baz()

—

class FooExtension:

 [extension]

 static def Baz():

 print "I'm a Foo Extension"
