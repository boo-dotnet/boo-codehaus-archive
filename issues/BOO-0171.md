## Description

The script below produces error "BCE0011: An error occurred during the execution of the step Boo.Lang.Compiler.Steps.EmitAssembly: Specified cast is not valid..":

import System

import System.Windows.Forms

class Test(Form):

 def constructor():

 Application.Idle += self.appIdle

 def appIdle(sender as object, e as EventArgs):

 Application.Idle -= self.appIdle

 print "Idle called"

Application.Run(Test())

Also, thinking that you might need to create and save the EventHandler object, and then reuse it when removing it from the event, I tried:

self._appIdle = EventHandler(self.appIdle)

This produced the error:

BCE0024: The type 'System.EventHandler' does not have a visible constructor that matches the argument list'(callable(System.Object, System.EventArgs) as unknown)'.

This happens because the signature for the appIdle is not completely known when the -= operator is used. This will be fixed.

As a workaround you can fully declare appIdle's signature:

def appIdle(sender, args as EventArgs) as void:

 ...

And no, it's not necessary to save the reference you used with += since the method signature is exactly the same as the event.

If you ever need to save the reference you just need to declare it with the apropriate type as can be seen in the following example:

 import System

 class Application:

 static event Idle as EventHandler

 static def Run(o):

 Idle(null, EventArgs.Empty)

 class Test:

 _idleHandler as EventHandler = Application_Idle

 def constructor():

 Application.Idle += _idleHandler

 def Application_Idle():

 Application.Idle -= _idleHandler

 print "Idle called"

 t = Test()

 Application.Run(t)

 Application.Run(t)

Thanks for the report!
