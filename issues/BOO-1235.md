## Description

Testcase:

```
"""
23
23
42
"""

class Param[of T]:
 [getter(Value)]
 value as T

 def constructor(value as T):
 .value = value

def Foo[of T](*params as (Param[of T])):
 for p in params:
 print p.Value if p

a = Param[of int](23)
b = Param[of int](42)
Foo(a)
Foo(a, b, null)

```

On 0.9.1, last two lines give BCE0164: Cannot infer...
