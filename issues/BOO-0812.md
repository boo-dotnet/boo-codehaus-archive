## Description

From the mailing list post by Socrates877:

Make a class A with a static method Explosion(). In Explosion(), call

a static method on another class B. Make a non-static property in

class A with the same name as class B.

class A:

 [property(Attribute)]

 _attribute as Attribute

 static def Explosion(property as System.Reflection.PropertyInfo,

attributeType as Type):

 x = Attribute.GetCustomAttribute(property, attributeType)

An instance of type 'Lucid.Data.A' is required to access non static

member 'Attribute'. (BCE0020)

### Max Bolingbroke, 01/Apr/07 6:08 AM

OK, this is caused by the call "ResolveName(node, node.Name)" in ProcessMethodBodies.OnReferenceExpression. It seems that NameResolutionServices just stops resolving the name when it finds the Console property, so never looks at the Console type. I think the correct behaviour would be to return an Ambiguous entity and fix it up in ProcessMethodBodies?
