## Description

It is pretty hard to sport misspelled varible names since they are declared when they are assigned.

The classical solution would require the programmer to declare name and type for each variable and lead to a lot of unnecessary typing.

VbScript offers slightly different approach: You can (with "option explicit") enforce the declaration of each variable name with "Dim myVariable". Since VbScript has no type concept, type assignments are not necessary.

Would it be possible to have something similar in boo?

Example:

def reducedNetPrice( netPrice as int ):

 VARS netDiscount, errorMsg, someVar, sum, i

 netDiscount = 0.05
