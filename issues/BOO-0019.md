## Description

Define some kind of IExpando/IQuack/IAmADuck interface that allows custom types to customize the processing of method invocations and property accesses during duck typing:

 interface IQuack:

 def QuackInvoke(methodName as string, args as (object)) as object

 def QuackGet(propertyName as string) as object

 def QuackSet(propertyName as string, value as object) as object

This would allow expando like types to be defined.
