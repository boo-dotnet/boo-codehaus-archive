## Description

Attached are the source and binaries for an addin that will make a secondary display binding (those precious little tabs you see underneath a file's buffer) for .boo files that will show you what your Boo code will be expanded to before its compiled.

Just extract the -bin file somewhere in #dev's "Addins" folder, either in a folder by itself or in the root directory.

- BooGeneratedCodeViewer-bin.zip
