## Description

```
import System
import System.Collections.Generic

interface IFunc[of T,TResult]:
 def Do(arg as T) as TResult

class ConvertIntToHexStringFunc (IFunc[of int,string]):
 def Do(arg as int) as string:
 return arg.ToString("x")

def imap[of T1, T2](f as IFunc[of T1,T2], i as T1*) as T2*:
 for v in i:
 yield f.Do(v)

```

Compiles but generated invalid IL that crashes at runtime.
