## Description

string literals with a single char should be implicitly converted to char whenever necessary in assignments, function arguments and cast expressions.

 def printChar(ch as char):

 System.Console.Write(ch)

 c1 as char = "b"

 c2 = cast(char, "o")

 printChar("o")
