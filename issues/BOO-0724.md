## Description

[snip]

class Foo: 

 private _x as object 

class Bar(Foo): 

 private _x as string 

 def constructor(): 

 _x = "foo" 

[/snip]

This code causes the compiler to complain "Expression cannot be assigned to" on the _x = "foo" line.
