## Description

currently, you can do

assert &lt;cond&gt;

e.g. assert false

and

assert &lt;cond&gt;, &lt;string describing cond&gt;

e.g. assert false, "badness"

it'd be nice to be able to do

assert &lt;cond&gt;, &lt;exception&gt;

e.g. assert value is null, ArgumentNullException("value")
