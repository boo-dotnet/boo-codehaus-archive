## Description

First test:

create a very simple nunit TestFixture, with 1 Test : test.boo
 
compile it : PpcCompiled.dll
 
run it with nunit-console : no tests can be executed.

Second test:

run PpcCompiled on a x86 box with nunit-console : no tests can be executed.

Third test:

compile test.boo on a x86 box : x86Compiled.dll
 
run x86Compiled on x86 : it works (tests can be executed)
 
run x86Compiled on ppc : it works

Last test: 

recreate test source in C# (test.cs). Same functions.
 
compile it with mcs on the ppc box, run it : it works.
