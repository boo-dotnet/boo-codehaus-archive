## Description

The ability to infer this:

```
 Array.ConvertAll[of int, string] ( (1,2,3), { i as int | i.ToString() } ) 
```

...from this:

```
 Array.ConvertAll( (1,2,3), { i as int | i.ToString() } ) 
```
