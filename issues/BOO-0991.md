## Description

Using the keyword 
{or}

, create the following syntax:

```
for item in list:
 &lt;loop_block&gt;
or:
 &lt;or_block&gt;
else:
 &lt;else_block&gt;

```

which is equivalent to the pseudocode:

```
enteredLoop = false
:looptarget
if condition:
 enteredLoop = true
 &lt;loop_block&gt;
 goto looptarget
elif not enteredLoop:
 &lt;or_block&gt;
 goto elsetarget
else:
:elsetarget
 &lt;else_block&gt;
:afterloop

```

Allow the keyword break in either the &lt;loop_block&gt; or &lt;or_block&gt; to be equivalent to the instruction goto afterloop

The or and else blocks are independently optional and order-sensitive, i.e. the order must be for in/while ... or ... else when specified together.
