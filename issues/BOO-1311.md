## Description

This can occur when building Boo on a Windows system and the path to NAnt has a space in it (ex: C:\Program Files\NAnt\Bin). If I move NAnt to another directory, such as C:\0.90\NAnt\Bin, Boo builds fine. Attached is a verbose NAnt build log file that describes the error. The error message is at the bottom of the file.
