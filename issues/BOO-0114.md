## Description

Given

&gt;&gt;hello.boo&lt;&lt;

print("Hello world

&gt;&gt;&lt;&lt;

it could be useful to allow generate

&gt;&gt;generated.boo&lt;&lt;

import this

import that

#line 1 "hello.boo"

print("Hello world

&gt;&gt;&lt;&lt;

and to get, for examples, error messages from the compiler as coming from line 1 of hello.boo.

Another example is an embedded SQL preprocessor. The proeprocessor converts SQL statements to appropriate library calls and puts in #line pragmas that refer to the original SQL. This way the compiler would spit out line numbers in error messages that refer to the original source.

C# compiler #line directive

http://msdn.microsoft.com/library/default.asp?url=/library/en-us/csref/html/vclrfLine.asp
