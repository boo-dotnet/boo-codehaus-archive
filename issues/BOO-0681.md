## Description

I'm not sure which component this is a bug in.

Anyway, check this code-slice out.

"[assembly: AssemblyKeyFile("../src/boo.snk")]"

If you compile from C:\boo\src\Boo.Lang, booc looks for "C:\boo\src\boo.snk"

However, if you compile from c:\boo\src\Boo.Lang, AND use -o to set the output somewhere else, like "-o:c:\boo\build\bin," then booc looks for "C:\boo\build\src\boo.snk" which is, like, 2tally wrong.

The keyfile location is supposed to be relative to the AssemblyInfo file delcaring the AssemblyKeyFile attribute, as far as I know.
