## Description

The following valid boo program fails with System.InvalidCastException in the second call to sum:

def sum(items):

 value = 0

 for item as int in items:

 value += item

 return value

print(sum([1, 2, 3]))

print(sum([1L, 2L, 3L]))

The reason is that each item taken from the items argument is directly cast/unboxed to an int (the item loop variable). This is wrong.

The compiler should insert code to do the runtime check/conversion/promotion to the appropriate type.
