## Description

```
def foo():
 import Boo.Lang.Compiler.Ast
 return ReferenceExpression("foo") # ok, import in scope

r as ReferenceExpression = foo() # CompilerError: ReferenceExpression is not visible here

```

The idea is to allow macros to inject imports into specific blocks without polluting the module namespace.
