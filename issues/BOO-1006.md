## Description

Currently we can do this :

```
n = 42
print "hex(x) = {0:x4}" % (n,)

```

or this :

```
n = 42
print "hex(n) = ${n.ToString('x4')}"

```

It would be nice to be able to do this :

```
n = 42
print "hex(n) = ${n:x4}"

```
