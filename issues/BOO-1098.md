## Description

The following results in the following output...

1

5

0

import System.Collections.Generic

i1 as int

i2 as int?

l = List[of int]()

i2 = 5

l.Add(i2)

print l[0]

l.Add(i2.Value)

print l[1]

i2 = null

l.Add(i2)

print l[2]

i1 = i2

print i1

The final assignment from a null nullable results in an

InvalidOperationException which makes sense. It looks like Boo is

trying to automatically convert between nullable and nonnullable

values, but something isn't working right when a nullable is passed

into a parameter expecting a nonnullable...
