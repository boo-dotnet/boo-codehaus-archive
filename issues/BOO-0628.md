## Description

Code generation using the "Auto code generation" produces C# code, while generating the code for an interface by clicking on the class symbol produces Boo code.

Ex:

#click on class icon, generate implictly.

class Test(ICodeGenerator):

 public final def IsValidIdentifier(value as string) as bool:

 raise NotImplementedException()

 public final def ValidateIdentifier(value as string) as void:

 raise NotImplementedException()

#Alt-Ins, "Interface Implementation"

class Test(ICodeGenerator):

 public bool IsValidIdentifier(string value) 
{
 throw new NotImplementedException();
 }

 public void ValidateIdentifier(string value) { throw new NotImplementedException(); }
