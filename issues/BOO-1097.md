## Description

The FullName property of IMethod and IType objects returns inconsistent results between internal and external entities and between simple, generic or constructed entities.

In cases where the FullName behavior is consistent, it is coded separately in several places which creates code duplication and obfuscates the intent. 

For example, an external method's FullName will return only its declaring type and name, whereas an internal method's FullName property will include the parameter list.
