## Description

Now that we can define macros with specific arguments (cf. BOO-1146), it would be nice to support macro overloads as well :

```
macro config.option(name as string, value as string):
 yield [| print "${$name} = string(${$value})"

macro config.option(name as string, value as int):
 yield [| print "${$name} = int(${$value})"

```
