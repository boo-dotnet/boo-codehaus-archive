## Description

I think the strict mode should force the programmer to implement interface methods.

## Comments (2)

---

### Cedric Vivier, 05/Aug/10 8:49 PM - edited

I'm not fan of this change, strict mode is about privileging safety over convenience with regards to some features of Boo that, while handy sometimes, may result in unintended behavior at runtime in other times.

Implementation stubs are convenient and do not lead to unintended issues imho, especially since there is warnings at each generation of each of those.

Also, if desired it's already possible to use -warnaserror compiler option to make sure a build fail when there is interface implementation stubs.
