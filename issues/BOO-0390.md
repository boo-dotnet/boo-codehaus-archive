## Description

I've run into it using log4net:

[assembly: log4net.Config.DCOMConfigurator()]

This cause an error, since the log4net.Config contains both:

DCOMConfigurator and DCOMConfiguratorAttribute

csc handles it properly, and I think that booc should as well.

The easy workaround is to append Attribute to the attribute, though.
