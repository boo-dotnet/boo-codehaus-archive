## Description

It would be extremely convenient to include a simple Makefile for the purposes of compiling Boo from source, to avoid the dependency on NAnt, especially due to some strangeness with NAnt under mono.

I've attached such a simple makefile – there's little to no dependency tracking, so if anyone is actually working on modifying Boo they should probably use NAnt (or just blow away the build directory), but it does get things built for me nicely.
