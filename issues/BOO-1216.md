## Description

By default .booproj's have the value &lt;Platform&gt;AnyCpu&lt;/Platform&gt; set, which will allow x64 machines to Jit to x64 code, however SharpDevelop cannot debug x64 applications. 

In C#, setting the platform tag to the value:

&lt;Platform&gt;x86&lt;/Platform&gt;

would force the project to compile to x86 specifically which SharpDevelop can debug (even on an x64 machine). Without this the end result is that boo executables are not debuggable on x64 machines, which makes it nearly impossible to work with.

This is a major blocker for me.
