## Description

Boo should be able to shadow/hide methods.

C# example:

class BaseClass { public BaseClass Clone() 
{ return new BaseClass(...); }

 }

class SomeClass : BaseClass { public new SomeClass Clone() 
{ return new SomeClass(...); }

 }

It should use a keyword (like "shadow" or "new").

This is important for compiling with the C#/VB parser because many C# applications use this feature.
