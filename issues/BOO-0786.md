## Description

The current SingletonAttribute expands in a way that is not thread-safe. Race conditions can occur between checking if instance is instantiated and its instantiation. As well, the solution is not elegant enough to prevent instantiation until the user specifically requests it. This fixes that issue.

Note: Design considerations recommend that there should be no need to have static methods on the singleton other than Instance (which SingletonAttribute generates automatically). Static members on the singleton generate warnings alerting a user to the likelihood of poor design. A warning is generated once per singleton class with a static member.
