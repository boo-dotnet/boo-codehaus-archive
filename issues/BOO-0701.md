## Description

arr = (1,2,3)

testbyref(arr[0])

works for internal method calls but not external, because arr[0] has a null entity.

Ignoring null entities in callableresolutionservice.canloadaddress fixes the problem, doesn't break any tests, and peverify doesn't complain.
