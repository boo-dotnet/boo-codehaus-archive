## Description

The code:

 a, b = 1, 2

is emitted today as something roughly equivalent to:

temp = (1, 2)

a = temp[0]

b = temp[1]

There's no point in creating the array in the first place. The stack itself is sufficient to store the values.

Notice that the semantics must be preserved: ALL the expression on the right of the assignment should be evaluated before the first assignment to any element on the left.
