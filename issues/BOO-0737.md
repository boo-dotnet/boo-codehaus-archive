## Description

Code sample:

i, j = 1, 5 

a, b = "a", "b" 

i == j // not ignored

a == b //ignored

------------------------------

class C: 

 static def op_LessThan(this as C, other as int) as bool: 

 return true 

c = C() 

c &lt; 3 //no error, this is ignored

"It is okay to ignore the results of normal method calls, but even 

though == is converted to an Equals method call, the results should not 

be ignored in this case because it can cause mistakes to go unnoticed"

Example: a == b instead of a=b
