## Description

The goal is to allow boo to be embedded directly into asp.net pages:

&lt;%@Page Language="boo" %&gt;

&lt;script runat="server"&gt;

def Page_Load(sender, args as EventArgs):

 _msg.Text = "Hello from boo!"

&lt;/script&gt;

&lt;html&gt;

&lt;body&gt;

&lt;asp:Label id="_msg" runat="server" /&gt;

&lt;/body&gt;

&lt;/html&gt;

This probably involves integration between System.CodeDom and Boo.Lang.Compiler as well as some asp.net configuration love.
