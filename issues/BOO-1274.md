## Description

XmlTextReader is not recognized when running booish.exe (see screenshot). Every thing works fine when compiling with booc.exe.

The error seems to occur when multiple name spaces are imported, since removing the import statements for System.Data and System.Data.OleDb fixes the problem.

The input source (file or keyboard) does not seem to be relevant.
