### Dmitry Malyshev, 17/Mar/10 11:44 AM

It hangs somewhere in closure processing. ONLY when the struct is passed by reference (removing the 'ref' makes it compile correctly).

Here is the simplified test case:

```

public struct Key[of T]:
 public t as single

public def fun[of T(struct)](a as T, time as single) as T:
 x = {ref k as Key[of T]| return k.t &gt; time}
 return a

```
