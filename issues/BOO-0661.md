## Description

When Boo compiler is running on .Net 2.0, the following code produces exception in Boo.Lang.Compiler.Steps.EmitAssembly, "Could not load type 'MyClass' from assembly '1, Version=0.0.0.0, Culture=neutral, PublicKeyToken=null'."

class MyClass:

 struct MyStruct1:

 a as int

 b as int

 c as MyStruct2

 struct MyStruct2:

 a as int

 b as int

 a as MyStruct1

 b as MyStruct2

That's strange to me, as when CreateType on MyStruct1 is called, MyClass should already be in the middle of CreateType and TypeResolve, so this shouldn't be happening. When Boo Compiler is running on .Net 1.1 error is not showing up.

Ok, I did some investigation, and found that this might be a bug in .NET 2.0. See attached C# source demonstrating the problem. Seems like for some reason it can't find Enclosing type, although it is already created, and .IsCreated() on that type returns true proving that.
