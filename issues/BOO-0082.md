## Description

In a recent chat with Rodrigo, we had the idea of coming up with a XSLT pipeline step.

This step could implement a DOM source for the AST, or serialize the AST into an XML file, call an XSL Transformation, and optionally convert the resulting XML back into AST form, and proceed.

This would greatly simplify documentation-writing pipeline steps, and would open up very interesting ways to do AOP (XPath becoming a query language and all) and some other wacky, wacky stuff.
