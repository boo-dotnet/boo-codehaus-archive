## Description

I'm not sure if this is a limitation with how macros work, but assert currently does not allow certain expressions that you would expect to work 

&gt;&gt;&gt; assert true

&gt;&gt;&gt; assert 1==1

&gt;&gt;&gt; (1,2) == (1,2)

true

&gt;&gt;&gt; assert 
{1: "this is ok"}

&gt;&gt;&gt; assert (1,2) == (1,2)

----^

ERROR: Unknown identifier: 'assert'.

&gt;&gt;&gt; [1,2,3] == [1,2,3]

true

&gt;&gt;&gt; assert [1,2,3] == [1,2,3]

----^

ERROR: Unknown identifier: 'assert'.
