## Description

The following should assign the parameters in the constructor to the current structures members.

However, Boo doesn't like it when you put a comma after self.anything.

struct test:

 start as int

 end as int

 def constructor(start, end):

 self.start, self.end = (start, end)

tester = test(1, 2)

It's the any member reference expression (x.y) or slicing expression or whatever that doesn't work. The unpack rule in the parser need to allow a slicing_expression or a declaration, and the ast for unpackstatements need to be changed, among other changes.

class A:

 public static One as int

 public static Two as int

A.One, A.Two = 1, 2 //fails

l = array(int, 2)

l[0], l[1] = 1,2 //fails

print "ok"
