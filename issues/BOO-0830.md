## Description

Adding the substraction operator on boo arrays would be a nice handy feature :

&gt;&gt;&gt;cities = ['Tokyo', 'Barcelona', 'Moscow', 'Kuala Lumpur', 'Sidney']

&gt;&gt;&gt;visited = cities - ['Moscow', 'Sidney']

Would give:

['Tokyo', 'Barcelona', 'Kuala Lumpur']

Also there is surely a bug with array's '+ operator' :

&gt;&gt;&gt; cities = ['Tokyo', 'Barcelona', 'Moscow', 'Kuala Lumpur']

&gt;&gt;&gt;cities += 'London'

Gives:

['Tokyo', 'Barcelona', 'Moscow', 'Kuala Lumpur', L, o, n, d, o, n]

Hardly the expected and preferable behavior I think?

### Avishay Lavie, 21/May/07 3:21 PM

I agree - this behavior is highly unintuitive. Technically it's rather hard to circumvent (perhaps just hard-coding a special case for strings?) but that doesn't make it less of a (bad) surprise. 

A different option would be to separate the add-single-item and the concatenate-with-other-list behavior. Consider, for example, reserving "+" for "add this item" and "&amp;" for "concatenate with items in this enumerable". 

```

cities = ['Tokyo', 'Barcelona', 'Moscow', 'Kuala Lumpur', 'Sidney']
cities += 'London'
&gt;&gt;&gt; ['Tokyo', 'Barcelona', 'Moscow', 'Kuala Lumpur', 'Sidney', 'London']
cities &amp;= 'London'
&gt;&gt;&gt; ['Tokyo', 'Barcelona', 'Moscow', 'Kuala Lumpur', 'Sidney', 'London', L, o, n, d, o ,n]

```
