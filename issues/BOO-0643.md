## Description

Consider these overloaded methods from recent GTK# 2.4.0 library:

InsertWithTags(TextIter, string, params TextTag[])

InsertWithTags(ref TextIter, string, params TextTag[])

Since boo doesn't require/accept ref in function call, it is imposssible to call the second overload. Always the first is called.

Boo itself doesn't allow to create such overloads, but C# does
