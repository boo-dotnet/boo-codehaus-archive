## Description

Testcase:

```
abstract class Base:
 abstract protected def Foo():
 pass

abstract class Derived (Base):
 pass

class Concrete (Derived):
 override protected def Foo():
 pass

```

Gives:

```
BCE0090: Derived method 'Concrete.Foo' can not reduce the accessibility of 'Derived.Foo' from 'public' to 'protected'.
```

Because Derived is expanded as :

```
public abstract class Derived(Base):

 protected def constructor():
 super()

 ***public*** override def Foo() as void:
 pass

```

Accessibility should be preserved when a stub is created.
