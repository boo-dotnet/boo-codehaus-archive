The fix for this appears to be very simple. Around line 62 in src/boo.lang.compiler/steps/expandmacros.cs, just use ResolveQualifiedName(BuildMacroTypeName(node.Name)) by default instead of trying ResolveQualifiedName(node.Name) first.

IEntity tag = tag = NameResolutionService.ResolveQualifiedName(BuildMacroTypeName(node.Name));

//(now you won't need the if block below this line)

And now the print statement works. The other macros still work fine too.

This version of booi.boo supports more command line options:

"d" or "debug" turns debugging off (it is on by default). "-d" or "-debug" or "-debug+" keep debugging on AND prints debug messages out to the console (if you are not using a debug viewer). "-v" or "-vv" or "-vvv" prints trace messages out to the console just like in booc.
