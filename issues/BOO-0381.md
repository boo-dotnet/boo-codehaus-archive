## Description

This patch let's you assign attributes to an auto-generated property, and let's you use the required attribute on properties (adds parameter check to the setter).

class Customer:

 [property(FirstName, Attributes:[Required])]

 _fname as string

class A:

 _fld1 = "abc"

 [Required]
