## Description

Testcase:

```
private class Foo:
 public def NonVisibleMethod(): #! warning though method is not visible outside the assembly
 return false

```

In strict mode (the default for SharpDevelop, it seems), the compiler warns you about unspecified types on public methods in classes.

However, it also does it when the classes are not public. This seems excessive, given the expressed intent of preventing changes in public APIs. These are not public APIs. It would be nice if it did not do this, as it wastes a lot of time.
