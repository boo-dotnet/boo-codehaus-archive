## Description

The compiler should declare a temporary variable at the calling point and generate a warning (value of temporary will be discarded).

def foo(ref i as int):

 i = 3

value as object

value = 2

foo(value) # generate warning here

assert 2 == value # of course

value = "foo"

foo(value) # invalid cast exception in runtime
