## Description

```
class Foo(IQuackFu):
 final _foo as (string)

 def constructor(*foo as (string)):
 self(1, *foo)
 
 def constructor(bar as int, *foo as (string)):
 self(1, 2, *foo)
 
 def constructor(bar as int, baz as int, *foo as (string)):
 _foo = foo

```

With the chains expanding incorrectly to runtime resolution.
