## Description

Right now #develop "kinda sorta" does code completion for generator statements only if you explicitly declare the type.

l = [1, 2, 3]

var = e for e as object in l if e.CompareTo(5) &gt; 0

It would be nice if #develop recognized "e for e (optional as) in l" and did code completion on e.
