## Description

Overlay assemblies would allow redefining/extending external third-party types and methods in a more general way than extension methods (and also enables before/after/around AOP on external members quite easily).

An overlay assembly overrides type/member resolution of the overlayed assembly when there is a match in both.

Eg:

```
#build this code as mscorlib.Overlay.dll
[assembly: Overlay("mscorlib")]

[NamespaceOverlay("System")]
class Console:

 [ConditionalAttribute("ALLOW_WRITELINE")] #can define new attributes too
 static def WriteLine(text as string):
 print "@${date.Now}: ${text}" #overlays do not override themselves

```

Then IF building with `booc -r:mscorlib.Overlay.dll -d:ALLOW_WRITELINE` :

```
print "hello world!"

```

Output would look like:

```
@02/09/2009 20:36:29: hello world!

```

Building with `booc -r:mscorlib.Overlay.dll` without ALLOW_WRITELINE symbol, output would be empty (""), since we overlayed Console.WriteLine with ConditionalAttribute.
