## Description

Hi,

As discussed on the mailing list, this behavior is incorrect. http://groups.google.com/group/boolang/browse_thread/thread/5ba406bceb4cff03

Here is example code:

class Foo:

 def constructor():

 self.init() 

 abstract def init():

 pass

class Bar(Foo):

 hello as string = "Bug!"

 def constructor():

 super()

 print self.hello

 def init():

 self.hello = "Everything is OK!"

Bar()
