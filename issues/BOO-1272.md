In C#, the OverflowException is what I would expect. 0xffffffff represents the int -1, and assigning a negative number to an uint will result in an exception.

However, Boo seems to have an issue with type inference for 0xffffffff.

Using:

i = 0xffffffff

print "$
{i}

 ($
{i.GetType()}

)"

I get "-1 (System.Int64)" which is nonsense - Boo should decide on either "-1 (System.Int32)" or "4294967295 (System.Int64)"
