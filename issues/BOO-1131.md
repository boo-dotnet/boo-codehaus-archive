## Description

Would be nice to be able to define macro accessibility ie:

```
private macro foo:
 yield

```

Would be useful for macros intended to be used from its declaring assembly only.

Consequently it will not need to be actually emitted so that to keep the assembly lean and mean (not referencing Boo.Lang.Compiler).

A macro would have the same default visibility than a class.
