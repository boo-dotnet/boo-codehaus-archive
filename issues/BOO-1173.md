## Description

booc (...) -r:debug.dll,BeIT.dll,System.Web.dll

Boo Compiler version 0.9.0.3203 (CLR v2.0.50727.1433)

Fatal error: Cannot find assembly: 'debug.dll,BeIT.dll,System.Web.dll'.

workaround :

booc (...) -r:debug.dll -r:BeIT.dll -r:System.Web.dll
