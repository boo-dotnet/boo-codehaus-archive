## Description

See attached solution for example. There are two Boo projects in the solution. Project 1 defines an interface with an event. Project 2 defines a class that implements the interface. When the code is compiled, this error is thrown: 

An error occurred during the execution of the step 'Boo.Lang.Compiler.Steps.EmitAssembly': 'Method 'add_SweetEvent' in type 'InterfaceCompileError.Stubs.SweetStub' from assembly 'Stubs, Version=1.0.2856.0, Culture=neutral, PublicKeyToken=null' does not have an implementation.'. (BCE0011)

If we move the class file into the same project as the interface, compilation succeeds.
