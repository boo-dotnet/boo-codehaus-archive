## Description

Currently, quite counter-intuitively imo, 'coalesced' cases like:

```
case some_long_pattern
case another_long_pattern:
 DoSomething()

```

Are expanded to:

```
case some_long_pattern:
 pass
case another_long_pattern:
 DoSomething()

```

Instead of :

```
case some_long_pattern | another_long_pattern:
 DoSomething()

```

I'd guess changing behavior to latter example would make sense for `intuitivity` and allow more readable long either (|) patterns (instead of all on one line).

Thoughts?
