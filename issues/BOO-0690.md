## Description

I'm often naming temporary mini scripts 1.boo, 2.boo and so on. boo-0.7.6.2156 reports error:

BCE0135: Boo.Lang.Compiler.CompilerError: Invalid name: '1Module'

when I run 'booi 1.boo'. Contents of 1.boo do not matter, it can be as simple as print "hello world". Version 0.7.5 did not have this problem.
