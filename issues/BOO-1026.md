## Description

Boo compiler spits out an error given this testcase:

class A[of T]:

 callable Exp() as T

 def foo(exp as Exp):

 return exp()

def bar():

 return 7

a = A[of int]()

assert a.foo(bar) == 7

Cedric tells me under 8.2, the error is (don't have 8.2 installed yet personally):

tmp/13244.boo(12,13): BCE0017: The best overload for the method 'A[of T]`1[int].foo' is not compatible with the argument list '(callable() as int)'.
