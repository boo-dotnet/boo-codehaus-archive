## Description

The macros could be as simple as:

class UncheckedMacro(AbstractAstMacro):

 override def Expand(macro as MacroStatement):

 assert 0 == len(macro.Arguments) 

 macro.Block["checked"] = false

 return macro.Block

class CheckedMacro(AbstractAstMacro):

 override def Expand(macro as MacroStatement):

 assert 0 == len(macro.Arguments)
