## Description

I am using Phantom (http://github.com/JeremySkinner/Phantom) instead of default Boo shell.

But I verified that Phantom uses libs from Boo 9.2 and it is not rewriting this part of compilation, so I assume it's a Boo 9.2 issue.

When I do import Utilities.FTP from '.Libraries/FTPclient.dll', Boo/Phantom crashes with

BCE0000: D:\MyProject\build.boo(1,27): BCE0135: Boo.Lang.Compiler.CompilerError: Invalid name: '.Libraries/FTPclient.dll'

However, if I move the library to 'lib' folder and do import Utilities.FTP from 'lib/FTPclient.dll', everything works.

I assume this is an issue with folder name '.Libraries'. However, it is a valid folder name.
