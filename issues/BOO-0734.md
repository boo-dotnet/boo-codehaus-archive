## Description

The following code produces an "ERROR: Ambiguous reference..."

class MyData:

 def LoadFile(file as List):

 pass

 def LoadFile(file as string):

 pass

data = MyData()

for d in ["File1.txt", "File2.txt"]:

 data.LoadFile(d) &lt;&lt; it works if I convert it to a string (i.e. d.ToString())

This is normal behavior. [] is the syntax to create a Boo.Lang.List, which only returns objects.

You don't have an overload that accepts an object, so the compiler freaks out, not knowing which method to resolve to.

In your example above, you should use the () syntax, which designates arrays.

[] = list of objects.

() array of (whatever type is shared by all items in the array)

for item in ('File1.txt', 'File2.txt') # ... works correctly, since you've created an array of strings to enumerate over, not a list of objects.
