## Description

I noticed that boo constructors have to manually assign constructor parameters onto fields. This is a very common and repetitive code pattern, which I believe can be automated. 

Constructor parameters get annotated with [Field], which introduces an implicit assignment operation onto a field with the specified name, defaulting to same name (or same name with leading _):

class Example:

 _name as string

def constructor([Field(_name)] name as string):

Note that since the parameter and field share the same variable name, we could also use the short form here:

def constructor([Field] name as string):
