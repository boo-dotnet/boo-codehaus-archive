## Description

Currently in Boo (or C# actually) when you define a bitfield enum (a enum type with System.FlagsAttribute applied) you have to define every value manually to have something useful :

```
[Flags]
enum Java:
 Ca = 1
 Fe = 2
 Ba = 4
 Be = 8

```

Eventually it would be nicer if Boo automatically sets enumeration constants in powers of two, that is, 1, 2, 4, 8, and so on if an enum has Flags attribute applied.

It would allow :

```
[Flags]
enum Java:
 Ca
 Fe
 Ba
 Be

```

Of course it is still possible to define some commonly used flag combinations manually [1] :

```
[Flags]
enum Java:
 None = 0
 Ca
 Fe
 CaFe = Ca | Fe //3 (1|2)
 Latte = 4
 Ba //8 since 4 is taken
 Be
 BaBe = Ba | Be //24 (8|16)

```

[1] : we need BOO-485 to be fixed first (at least for references within same enum).
