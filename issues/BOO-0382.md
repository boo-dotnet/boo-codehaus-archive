## Description

This patch to src/booc/App.cs allows booc to check the current working directory for dlls referenced by import..from statements, making it work like booi does. BOO-209 was updated as well.

Both booc and booi still also find dlls in the GAC or in the same folder as booc and booi. And booc still can find dlls specified by -r flags.
