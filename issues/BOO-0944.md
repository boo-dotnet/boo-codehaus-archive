## Description

Let's say we have the following AST attribute :

namespace Test

import Boo.Lang.Compiler.AstW

class TestAttribute(Boo.Lang.Compiler.AbstractAstAttribute):

 [Property(Foo)]

 _foo = false

 def Apply(node as Node):

 pass

If we use named arguments to set the Foo property, compiler will crash with an exception :

import Test

[test(Foo: true)]

def Bar():

 pass
