## Description

booish.exe doesn't work with final version of .net 2.0.

use this as booish.exe.config:

&lt;?xml version="1.0" ?&gt;

&lt;configuration&gt;

 &lt;startup&gt;

 &lt;supportedRuntime version="v2.0.50727" /&gt;

 &lt;/startup&gt;

&lt;/configuration&gt;

run booish.exe and you will get this error:

Unhandled Exception: System.TypeLoadException: Illegal definition for runtime implemented delegate method.

 at Boo.Lang.Interpreter.InteractiveInterpreter.___initializer()

 at Boo.Lang.Interpreter.InteractiveInterpreter..ctor()

 at BooishModule.Main(String[] argv)
