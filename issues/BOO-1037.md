## Description

It would be nice to have a one-line loop shortcut, e.g.:

print for i in range(10)

print(e.Current) while e.MoveNext()

Including this shortcut would be consistent with the shortcuts for if and unless. I understand that it may conflict with generators, however. Consider:

x = i for i in range(10)

Should this assign a generator to x or should it set x to i 10 times?

When I first learned boo, I started with the basic flow control syntax as I think most people would. I thought that a one-line loop would work because a one-line if statement worked. It was confusing because because sometimes the code would compile because I had accidentally created a generator but the program would yield unexpected results. I think other people could easily make the same mistake.
