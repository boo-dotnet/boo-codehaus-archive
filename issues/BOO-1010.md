## Description

When a space exists in the path to the NAnt.exe executable, CMD.exe does not correctly parse the command-line arguments for &lt;exec&gt; tasks with &lt;arg&gt; values, specifically, in the Boo.NAnt.Tasks target of default.build file. Because $
{nant::get-base-directory}

 returns a trailing-slash on the directory name, CMD.exe mistakenly parses everything after that as part of the -lib argument.

The attached patch file strips the trailing backslash from the path to the NAnt.exe executable if it exists.

I have tested this modified build file for NAnts that exist at paths that contain and do not contain spaces. My specific tests were to run NAnt from both of the following directories to build Boo:

C:\NAnt\NAnt.exe

C:\Program Files\nant\bin\NAnt.exe
