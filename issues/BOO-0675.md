## Description

Check out the following booish sample:

&gt;&gt;&gt; import System.Threading

&gt;&gt;&gt; z = Thread(
{ print 'rwar' }

)

--------------^

ERROR: Ambiguous reference '.ctor': System.Threading.Thread..ctor(System.Threadi

ng.ThreadStart), System.Threading.Thread..ctor(System.Threading.ParameterizedThr

eadStart).

&gt;&gt;&gt;

By the context, there is only one delegate that can actually work – the "ThreadStart" delegate, because ParameterizedThreadStart delegate actually takes one parameter. The closure is parameterless, though.

Boo should be smart enough to automatically adapt functions to delegates that have the same signature. If there's no matching signature for any of the potential delegates, then Boo should panick.
