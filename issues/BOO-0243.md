## Description

A combine has two projects; BooLibrary and BooExecutable.

BooLibrary is a .NET assembly (.DLL).

BooExecutable is a .NET executable (.exe).

BooExecutable references BooLibrary directly via the "References" function built into SharpDevelop.

After one successful compile of BooLibrary, then making modifications, saving those modificatinos, and starting to compile the project, SharpDevelop fails to compile BooLibrary with a BCE011 (Boo.Lang.Compiler.Steps.SaveAssembly failed).

Note that this only occurs after the first compilation succedes, indicating that BooBinding is not releasing some I/O lock on the compiled assembly when the first compilation is complete.
