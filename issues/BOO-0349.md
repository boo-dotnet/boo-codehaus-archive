## Description

Every time you compile boo on Windows, ngen.exe adds new copies of all the dlls and booc.exe to the Windows GAC under &lt;root-drive&gt;:\WINDOWS\ASSEMBLY. They are never removed. This patch adds an uninstall nant target on windows that cleans the dlls and exe from the GAC.
