## Description

abstract class A:

 protected abstract def A():

 pass

abstract class B(A):

 pass

class C(B):

 protected override def A():

 pass

Attempting to compile this will give: 

BCE0090: Derived method 'C.A' can not reduce the accessibility of 'B.A' from 'public' to 'protected'.
