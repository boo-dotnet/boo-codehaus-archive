## Description

The compiler shouldn't let you use override there since there is not

method named Equals with the appropriate signature to be overriden.

On Fri, 19 Nov 2004 14:35:10 -0500, redacted@gsk.com

&lt;redacted@gsk.com&gt; wrote:

&gt; 

&gt; I would have expected this to work: 

&gt; 

&gt; override public def Equals(other as Var) as bool: 

&gt; return self._name.Equals(other.Name)

&gt; 

&gt; And it does - but only when explictly calling Equals, not when using the ==

&gt; operator - why? 

&gt; 

&gt; print(V == V1) // ==&gt; False 

&gt; print(V.Equals(V1)) // ==&gt; True 

&gt; 

&gt; - Bill

&gt; 

&gt; 

&gt; redacted@webbness.com wrote on 11/19/2004 08:30:19 AM:

&gt; 

&gt; 

&gt; 

&gt; &gt; Consider the following:

&gt; &gt; 

&gt; &gt; &lt;snip&gt;

&gt; &gt; class Var(object):

&gt; &gt; 

&gt; &gt; [property(Name)]

&gt; &gt; _name as string

&gt; &gt; 

&gt; &gt; def constructor(s):

&gt; &gt; """I am a variable. My only argument is a string 

&gt; &gt; identifier."""

&gt; &gt; _name = s

&gt; &gt; 

&gt; &gt; override def ToString():

&gt; &gt; return self._name

&gt; &gt; 

&gt; &gt; override def GetHashCode():

&gt; &gt; return self._name.GetHashCode()

&gt; &gt; 

&gt; &gt; override public def Equals(other) as bool:

&gt; &gt; if other is Var:

&gt; &gt; return self._name.Equals(cast(Var, 

&gt; &gt; other).Name)

&gt; &gt; return false

&gt; &gt; 

&gt; &gt; def NotEquals(other):

&gt; &gt; return not self.Equals(other)

&gt; &gt; 

&gt; &gt; V = Var("Test")

&gt; &gt; V1 = Var("Test")

&gt; &gt; print(V)

&gt; &gt; print(V1)

&gt; &gt; print(V == V1)

&gt; &gt; print(V.Equals(V1))

&gt; &gt; 

&gt; &gt; print( Var("x").Equals(Var("x")) )

&gt; &gt; print( Var("x") == Var("x") )

&gt; &gt; &lt;/snip&gt;

&gt; &gt; 

&gt; &gt; Equals always returns false because 'other' is never a 

&gt; &gt; Var. Curious...

&gt; &gt; 

&gt; &gt; I looked at the compiled code in Reflector, C# style, and 

&gt; &gt; the Equals method looks like this:

&gt; &gt; &lt;snip&gt;

&gt; &gt; public override bool Equals(object other)

&gt; &gt; {

&gt; &gt; if(other == typeof(Var))

&gt; &gt; 
{
&gt; &gt; return this._name.Equals(((Var)other).Name);
&gt; &gt; }

&gt; &gt; return false;

&gt; &gt; }

&gt; &gt; &lt;/snip&gt;

&gt; &gt; 

&gt; &gt; So...

&gt; &gt; In my Boo Equals override do I need to write, which by the 

&gt; &gt; way works just fine:

&gt; &gt; 

&gt; &gt; &lt;snip&gt;

&gt; &gt; override public def Equals(other) as bool:

&gt; &gt; if other.GetType() is Var:

&gt; &gt; return self._name.Equals(cast(Var,
