## Description

Stuart Rackham wrote:

The modulus binary operator has been extended to expressions

like:

 &lt;format-string&gt; % &lt;iterator&gt;

Where the &lt;format-string&gt; can contain .NET Framework format

specifiers and &lt;iterator&gt; is an object supporting the

IEnumerable interface. For example:

 print("
{0:#,##0}

 is 
{1}

" % [1000, "one thousand"])
