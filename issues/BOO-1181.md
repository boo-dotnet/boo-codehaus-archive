## Description

Using several popular open source unit testing frameworks, it is possible to attach [Row(params...)] attributes to test methods. It looks like these attributes cause an internal compiler error. I tried every syntactic workaround, but none seemed to work. At the very least, a better message needs to be generated.

Here is a test case:

namespace Boo.Yaml.Test

import System

import MbUnit.Framework

[TestFixture]

class TestClassError: 

 [Test]

 [Row("something", 1)]

 def try_this(a as string, b as string):

 pass
