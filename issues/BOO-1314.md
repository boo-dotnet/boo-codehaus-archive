## Description

See http://community.sharpdevelop.net/forums/t/11789.aspx

1) add web reference to a Boo console project, e.g., http://dataworkssdk.ontimenow.com/FeatureService.asmx

2) attempt to compile the application: note the errors in the enum specifications in Reference.boo, which got generated with the Web Reference.

the enum names have parens (), which is a no-no
 
the enum items have "private" in front of them, which is a no-no (they are automatically private, I believe)
 
the enum items have "as int" which is a no-no (they are automatically int)

—

Looks like the CodeDom code doesn't have the necessary special cases to handle enums.
