## Description

Memoize attribute for Boo.Lang.Useful.Attribute

The attribute "memoizes" all calls to a (class or module) method and stores them in a hash. If a function is called again with the same parameters the result is retrieved from memory. This is called memoization or tabling.

The MemoizeAttribute has a debug flag that can be set to true. If set to true all memoizing actions will be written to the console.out

Usage

[Memoize(true)] #you can leave the true statement, but this will show usage of memoizing on the console

def fib(n as int) as int:

 if n &lt; 2:

 return 1

 return fib(n-1) + fib(n-2)

print fib(5)

print fib(4) #will be retrieved from memory
