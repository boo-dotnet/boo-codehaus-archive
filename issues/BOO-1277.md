## Description

When [immutable] is applied to a method, the compiler checks that the method does not modify any instance member (ie. guarantees that the method is side-effect free).

```
class Test:
 _x = 0

 [getter(Y)] //generated getters are [immutable]
 _y = 0

 [immutable]
 def Process(obj as object):
 _x++ //BCExxxx: Field `_x' cannot be modified in an immutable method.
 ProcessMutable(obj, _x) //BCExxxx: Mutable instance method `ProcessMutable' cannot be invoked from an immutable method.

 ProcessImmutable(obj, _x)
 ProcessImmutableWithOutArgument(obj, _x) //BCExxxx: Field `_x' cannot be modified in an immutable method.
 //TODO: add to error "Argument `XXX' of `XXX' is by reference. ??

 def ProcessMutable(obj as object, n as int):
 pass

 [immutable]
 def ProcessImmutable(obj as object, n as int):
 pass

 [immutable]
 def ProcessImmutableWithOutArgument(obj as object, ref n as int):
 pass

```

When compiling on .NET4 runtime, [immutable] also adds new [Pure] on the method for consumption by contract-checkers and other static analysis tools.
