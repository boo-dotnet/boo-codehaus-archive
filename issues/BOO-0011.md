## Description

should generate code to raise an exception in runtime may the condition evaluate to false.

When the message is omitted the macro should use the condition itself as the text for the message.

Changes to support the assert macro.

Added RuntimeException and AssertionFailedException to Boo namespace. Obviuosly, feel free to move to Boo.Lang and/or rename if you think that is more appropriate.

Added -debug[+|-] compiler switch to booc. If debug is turned off, then the assert macro expands to nothing.

Removed assert() builtin function as well as assert statement.

Added some test cases, but they assume that the debug option is set (so that the assert macro will raise an exception). Because I don't yet know how to compile different test cases w/ different compiler options, I made the debug option on by default. THIS IS PROBABLY NOT WHAT YOU WANT LONG TERM.

There are some do-nothing changes in the diff where jedit changed some existing space-indents to tabs. I left these in the diff since the new coding style document said to use tabs.
