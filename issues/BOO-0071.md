## Description

&lt;snip&gt;

assert [0, 1, 2] == List(range(3))

&lt;/snip&gt;

The current workaround is to invert the expression, this compiles and runs flawlessly:

&lt;snip&gt;

assert List(range(3)) == [0, 1, 2]

&lt;/snip&gt;
