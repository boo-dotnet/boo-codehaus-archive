## Description

The following fails to compile unless class B is declared first.

```
class A:
 l as B[of int]
 
class B[of TKey]:
 pass 

```

Error BCE0011: An error occurred during the execution of the step 'Boo.Lang.Compiler.Steps.EmitAssembly': 'Operation is not valid due to the current state of the object.'.

The problem is that DefineTypes() calls DefineTypeMembers() just after calling DefineGenericParameters(). The current algorithm seems to assume that all the member types have already had DefineGenericParameters() called for them.
