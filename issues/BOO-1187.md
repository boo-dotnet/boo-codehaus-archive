## Description

As I understand, nullable type casting should work in following way:

If there is a conversion from T to U, then there is a conversion from T? to U?, with null converting to null.

However, when I try to cast long? to int? (explicitly or not), it does not work:

Test.boo

```
x as long? = 5L
y = cast(int?, x)
print y
```

```
Test.boo(2,5): BCE0022: Boo.Lang.Compiler.CompilerError: Cannot convert 'System.Nullable' to 'System.Nullable'.

```
