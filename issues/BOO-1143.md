## Description

When I have multiple generic classes with the same name and various number of arguments, the compiler seems to have problems to pick the right class to inherit from.

class Test[of T]:

....pass

class Test[of T, S]:

....pass

class Derived(Test[of int, int]):

....pass

gives 

&gt; Boo Compiler version 0.9.0.3203 (CLR v2.0.50727.3053)

&gt; test.boo(7,15): BCE0004: Ambiguous reference 'Test': Test[of T], Test[of T, S].

&gt; 1 error(s).
