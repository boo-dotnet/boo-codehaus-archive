## Description

Treating duck typed expression as callable expressions allow things like (assuming ducky is set for the example bellow):

 def foo():

 print "foo"

 def bar():

 print "bar"

 fns = 
{ "foo": foo, "bar": bar }

 fns[prompt("foo or bar?")]()
