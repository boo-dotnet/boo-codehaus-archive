## Description

Make a class with a protected property, and it is emitted as public.

After the NormalizeTypeAndMemberDefinitions step, the source code is printing the getter and setter as public. Perhaps the SetPropertyAccessorModifiers() method in that step could be altered to handle protected/private and other modifiers not covered there.
