## Description

A clever and novel feature of BooBinding would be the ability to "send" the current active project (or any project right clicked) to the Boo Interactive Interpreter to allow for dynamic testing of compiled assemblies.

This could be accomplished by simply invoking the "load" function of the currently loaded interpeter pad.
