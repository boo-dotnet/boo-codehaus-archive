## Description

I have put together a zip containing the C# assembly, two 'boo' source files, and a nant build file, that demonstrates this problem. Please let me know if you would find this useful and I can send it to you.

This problem arises when I try and compile a dll from a boo file containing two classes. Each class implements an interface defined in an assembly written in C#.

When I implement one of the methods on an interface, the boo compiler complains that a different method does not have an implementation. 

I can cause different error messages to be output by the compiler depending on what order I place the method declarations in the C# interface definition.
