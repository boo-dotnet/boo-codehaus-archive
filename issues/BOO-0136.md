 Sorin Ionescu
 added a comment - 18/May/05 3:40 PM 

The problem is that the real switch only supports integrals. Any other type of object/operation is not supported. So, instead of a jump table we have to use IfStatement. Furthermore, we need special syntax for regex and more advanced stuff like:

given typeof(value):

 when int:

Do stuff

 when MyClass:
 
Do other stuff.

There is not going to be a generic Given. We just hope to support as much as possible. I don't know if it is the right thing to do though. We cannot support floating point types.
