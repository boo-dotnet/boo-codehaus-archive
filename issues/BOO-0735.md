## Description

This simple HTML page:

{{

&lt;%@ Page Language="Boo" Debug="True" %&gt;

&lt;html&gt;

&lt;head&gt;

&lt;title&gt;&lt;/title&gt;

&lt;style type="text/css" media="screen"&gt;@import url( intranet.css );

&lt;/style&gt;

&lt;/head&gt;

&lt;body&gt;

&lt;table&gt;

&lt;tr&gt;

 &lt;td align="middle"&gt;

 &lt;form name="t" method=GET&gt;

 &lt;/form&gt;

 &lt;/td&gt;

&lt;/tr&gt;

&lt;/table&gt;

&lt;/body&gt;

&lt;/html&gt;

}}

Results in a compile error (below) when viewed. However, making it a bit simpler allows it to compile. Any one of:

Removing the form elements
 
Removing the table division from around the form
 
Removing the style tag in the header

will allow it to compile. Also seen in larger pages with and without Boo source.

It doesn't seem related to a particular tag, or attribute value quoting style, or indentation. Just some arbitrary complexity seems to trigger it. I can't find one single thing that will do it, this is the simplest page I can cause it to repeatably happen for.

Have renamed the page, restarted IIS, cleared the Temporary ASP.NET Files folder to no effect.
