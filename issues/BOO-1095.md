## Description

```
class Bar:
 pass

interface IFoo:
 def Bar(ref x as Bar) as bool

class Foo (IFoo):
 def Bar(ref x as Bar) as bool:
 return true

x as Bar
Foo().Bar(x) #BCE0004: Ambiguous reference 'Bar': Foo.Bar(Bar), Foo.Bar(Bar), Foo.Bar(Bar).

```

If parameter 'x' is an external type instead of an internal type, it works.
