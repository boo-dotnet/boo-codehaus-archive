## Description

It would be nice to have some introspection features on IQuackFu.

It could then be supported - for instance for autocompletion of 'quackers' - in booish (currently booish2) ... and others.

I propose GetMembers(), which will return an IEnumerable of a new QuackFuMember struct :

struct QuackFuMember:

 name as string

 IsMethod as bool

 IsGetter as bool

 IsSetter as bool

 ArgumentsNames as (string) //return the names for each argument (if any)

 ArgumentsTypes as (object) //return the expected types for each argument (if any)

Full recap of the "current" iteration of the API (boo version) :

interface IReflectiveQuackFu(IQuackFu):

 def QuackGetMembers() as IEnumerable[of QuackFuMember]:

 pass

[Flags]

enum QuackFuMemberKind:

 Unknown = 0 #0000

 Method = 1 #0001

 Getter = 2 #0010

 Setter = 4 #0100

 Property = 6 #0110 Getter|Setter

struct QuackFuMember:

 Name as string

 Kind as QuackFuMemberKind

 ReturnType as Type #optional, can be null

 ArgumentNames as (string) #optional, can be null

 ArgumentTypes as (Type) #optional, can be null

 Info as string #optiona, can be null (arbitrary user-defined information about the member)

 override def ToString() as string #returns the 'boo-ish' string representation of the member
