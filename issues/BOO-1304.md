## Description

Command line compiler already accepts defines which are kept in CompilerParameters.Defines. 

The macro should allow simple boolean expressions on defines:

ifdef FOO:

 print "FOO"

ifdef FOO or BAR:

 print "FOO or BAR"

ifdef not FOO: 

 print "FOO is not defined"
