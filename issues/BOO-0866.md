## Description

The program 

import System

import System.IO

import System.Collections

import System.CodeDom

import Boo.Lang.CodeDom

def Main():

 prov as BooCodeProvider = BooCodeProvider()

 w = StringWriter()

 prov.GenerateCodeFromExpression(CodeTypeReferenceExpression(System.Environment.SpecialFolder), w, Compiler.CodeGeneratorOptions())

 print w

prints

System.Environment+SpecialFolder

Expected result:

System.Environment.SpecialFolder

This is causing problems for the SharpDevelop forms designer.
