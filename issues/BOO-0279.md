## Description

The Ant build-file for boox (boo/extras/common-properties.build) defines a sharpdevelop.dir property, and fails if it does not name an existing directory. When using Mono – obviously on Linux, but even on Windows – you can't use SharpDevelop, and you don't necessarily have it.

I commented out the &lt;fail&gt; element, and booxg built and ran just fine. I guess the property and requirement should be moved elsewhere.
