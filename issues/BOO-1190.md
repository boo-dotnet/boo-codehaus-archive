## Description

//compiles

[Extension]

static def WriteLine(me as Console, value as object, color as ConsoleColor):

 currentColor = me.ForegroundColor

 me.ForegroundColor = color

 me.WriteLine(value)

 me.ForegroundColor = currentColor

//fails at runtime with InvalidCastException

Console.WriteLine('oh, how it hurts me so', ConsoleColor.Red)

// Technically, one static method is just as good as another and it should be enough

// to just have a global def WriteLine and call the console methods. However,

// I like to group things together nicely (point of extension methds, right?)

// and regardless this should at least fail at compile time rather than runtime
