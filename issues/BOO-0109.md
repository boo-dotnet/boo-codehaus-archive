## Description

This would both simplify the EmitAssembly step while allowing for different type casting/numeric promotions strategies to be selected/tested/tried independently of the code emission logic.

One such strategy is to allow runtime numeric promotion to be selectively turned off by a macro:

options runtimeNumericPromotion=false:

 a as object = 3

 i as long = a

 // InvalidCastException on the previous line

 // since runtime numeric promotion was turned off
