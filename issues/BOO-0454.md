## Description

While writing up documentation for the PreErrorChecking step I noticed that constructors and destructors can be given return types and modifiers without the compiler caring. Well, destructors had stuff for modifiers but not for returns.

Example of this issue:

class Foo:

 private def constructor() as int:

 pass

 def destructor() as string:

 pass

f=Foo()

This compiles with no errors.

I've already fixed the problem but havin gprobs with svn - see, I dont really have svn properly set up with a working directory or none of that, I just edited stuff out of a tarball. So, attached is a summary of the edits. Its not hard to add though. 3 changes total over 3 files. Anyone who wants to is welcome to post a patch file.
