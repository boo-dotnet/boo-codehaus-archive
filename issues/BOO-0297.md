## Description

Enum members with explicit integer values can't be assigned negative values. This piece of code gives an "unexpected token" error:

 enum State:

 Deleted = -1

 Default = 0

 Public = 1

(This works:

 enum State:

 Deleted = 9999

 Default = 0

 Public = 1

)
