## Description

WORKS:

[code]

class MyClass:

 def DoSomething():

 print "I have done something"

class MySuperClass(MyClass):

 def DoSomething():

 cast(MyClass, self).DoSomething() # no "base" keyword in Boo?

 print "I have done something more!"

instance = MySuperClass()

instance.DoSomething()

[/code]

[output]

I have done something

I have done something more

[/output]

CRASHES:

[code]

interface IMyClass:

 def DoSomething()

class MyClass(IMyClass):

 def DoSomething():

 print "I have done something"

class MySuperClass(MyClass):

 def DoSomething():

 cast(MyClass, self).DoSomething() # no "base" keyword in Boo?

 print "I have done something more!"

instance = MySuperClass()

instance.DoSomething()

[/code]

[output]

Unhandled Exception: System.StackOverflowException: The requested operation caused a stack overflow.

 at MySuperClass.DoSomething () [0x00000]

 at MySuperClass.DoSomething () [0x00000]

 at MySuperClass.DoSomething () [0x00000]

 at MySuperClass.DoSomething () [0x00000]

(... repeated)

[/output]

(output with sigaltstack-enabled Mono, MS.NET popups a StackOverflowException debugger popup)
