## Description

Boo does not currently play nice with op_Implicit implementations written in Boo or any other CLS compliant .NET language; hence, the following example fails while it should work rightly:

import System.Drawing

def conv(p as PointF):

 print p

p = Point(0, 0)

conv(p)

The sample should work because Point implements op_Implicit to convert a Point structure to a PointF structure.
