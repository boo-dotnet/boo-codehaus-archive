## Description

Steps to reproduce:

1. Start booish

2. Type something on the command line (don't press enter)

3. Press home

4. Press the delete key (as many times you want)

Expected result: The character at the current cursor position should have been deleted and the rest of the line to its right should have been moved one unit to the lef

Obtained result: No effect

NOTE: I am submitting a patch to fix this problem. It has been diffed against the boo source code for boo version: 0.9.2.3383

Path to the source file: \boo-0.9.2.3383-src\src\Boo.Lang.Interpreter\InteractiveInterpreter2.boo
