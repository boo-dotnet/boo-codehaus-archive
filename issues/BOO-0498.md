## Description

The CollectionAttribute (or perhaps AbstractAttribute) appears to be using "is" for comparisons, and of course that does not work for value types.

I'm not familiar with the underpinnings of the code, but it should probably invoke the Equals member instead of doing an "is" comparison.

Sample:

import Useful.Collections from 'Boo.Lang.Useful'

[Collection(int)]

class collect:

 pass
