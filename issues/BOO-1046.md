## Description

If the file is not encoded with utf8 and you use some DBCS character in string, the output of string will be strange character after compiling.

That's because FileInput use File.OpenRead() and return TextReader.

The TextReader don't handle the encoding condition.

I suggest that use StreamReader() to handle.
