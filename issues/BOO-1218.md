## Description

Applying an the same attribute to method twice results in the following errors:

'...Attribute' cannot be applied multiple times on the same target. (BCE0154) - C:\Users\jchase\Documents\SharpDevelop Projects\...AttributeTests.boo:63,9

'...Attribute' cannot be applied multiple times on the same target. (BCE0154) - C:\Users\jchase\Documents\SharpDevelop Projects\...AttributeTests.boo:63,9

The custom attribute has the following attribute declared on it:

[AttributeUsage(AttributeTargets.Method | AttributeTargets.Constructor, true, true)]

The second parameter here is "allowMultiple", which is set to true. The compiler should check for the existence of the AttributeUsage attribute for the declared attribute and inspect the AllowMultiple property before returning error #BCE0154.

Additionally, if the error is legitimate it should only be displayed once.
