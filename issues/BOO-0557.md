## Description

Trying a simple compilation using booc gives the following error:

[fabio@carneirux AngMobile.Poketitos.Framework]$ booc .boo Macros/.boo Threading/*.boo -t:library

Unhandled Exception: System.ArgumentNullException: Argument cannot be null.

in &lt;0x003c9&gt; System.String:FormatHelper (System.Text.StringBuilder result, IFormatProvider provider, System.String format, System.Object[] args)

in &lt;0x0002b&gt; System.String:Format (IFormatProvider provider, System.String format, System.Object[] args)

in &lt;0x00037&gt; System.String:Format (System.String format, System.Object arg0)

in &lt;0x0001a&gt; Boo.Lang.ResourceManager:Format (System.String name, System.Object param)

in &lt;0x00762&gt; BooC.App:Run (System.String[] args)

in &lt;0x000e6&gt; BooC.App:Main (System.String[] args)

When forcing the execution to use the language-neutral locale, everything works ok:

[fabio@carneirux AngMobile.Poketitos.Framework]$ LANG=C booc .boo Macros/.boo Threading/*.boo -t:library
