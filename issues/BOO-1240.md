## Description

For an external file:

```
interface BaseInterface:
 def Add(s as string)

abstract class BaseAbstractClass:
 def Add(i as int):
 pass
```

And a consuming class:

```
class Consumer(BaseInterface,BaseAbstractClass):
 pass
```

the consuming class generates an EmitAssembly error:

BCE0011: An error occurred during the execution of the step 'Boo.Lang.Compiler.Steps.EmitAssembly': 'Method 'Add' in type 'Impl' from assembly [....] does not have an implementation 

This error ought be raised by ProcessInheritedAbstractMembers. Line 218 is suspect:

```
if (inheritedImpl is IExternalEntity &amp;&amp; entity is IExternalEntity)
 return true; //both sides are external, no need to check further
```
